## Route catalog, confirm rollback, and db listings

`GET /routes` (`api.catalog()`) publishes each route's upload constraints
and which features are on. Upload hooks fill `accept` / `maxFileSize` /
checksum from that catalog when you omit them.

Confirm and multipart complete now `DeleteObject` if HeadObject checks or
`onConfirmed` throw, then delete `previousKey` after a successful replace.
ACL on confirm comes from the upload policy — `resolveObjectAcl` is gone.

Download can return an inline disposition, a same-origin `GET /file`
proxy, or per-request `download.resolve` values. `deleteMany` deletes up
to 100 keys. Server-side uploads that should still run route policy use
`s3.put`.

The `db()` plugin stores a `route` column, lists with cursor / filters,
`getObject`, optional `quota`, and purge that can abort/delete on S3.

React adds `useObjectUrl` and `@dimah-s3/react/engine`.
Augment `DimahS3Routes` so hook `route` values match `dimahS3({ routes })`.
