## Faster, stricter Zod 4.5 request validation

Server endpoints compile Zod `body` / `query` schemas with `z.compile()`
on registration. Valid requests take the generated fast path; schemas
that cannot compile (for example `z.coerce`) keep the runtime parser.

Upload `checksum` must be a SHA-256 digest as standard base64 (padding
optional). Garbage values are rejected as `VALIDATION_ERROR` instead of
being forwarded to S3. Integers on protocol bodies use `z.int()`.
