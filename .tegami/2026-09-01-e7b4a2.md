## One `useUpload` — UI takes `upload`

Upload is a single hook. `maxFiles` (default `1`) is the only switch
between one file and a batch. The return shape is always `files[]`
(`file` is `files[0]`). Wired UI no longer owns the hook: pass the
instance as `upload`.

```tsx
const upload = useUpload({
  route: "images",
  maxFiles: 4,
  onSuccess: (results) => saveKeys(results.map((r) => r.key)),
});

return <UploadDropzone upload={upload} />;
```

Same instance drives `UploadButton`, `UploadStatus`, or a custom surface
(`getRootProps` / `open` / `handleFiles`).

## Wired download and delete take the hook return

Download and delete follow the same split, with one difference: the control
still takes `objectKey` (and display `fileName` / `fileSize`). The hook is
the route client; the button is the object.

```tsx
const download = useDownload({ route: "uploads", mode: "fetch" });
const del = useDelete({
  route: "uploads",
  onSuccess: () => refetch(),
});

return (
  <>
    <ProgressDownloadButton download={download} objectKey={storedKey} />
    <DeleteButton delete={del} objectKey={storedKey} />
  </>
);
```

`DownloadButton` takes a navigate-mode return; `ProgressDownloadButton`
takes `{ mode: "fetch" }`. Lifecycle callbacks stay on the hook. In a list,
call the hook inside the row.

### Removed

- `useMultiUpload`, `useFileUpload`, `useMultiFileUpload`
- `route` / engine options / lifecycle callbacks on `UploadButton`,
  `UploadDropzone`, `DownloadButton`, `ProgressDownloadButton`, and
  `DeleteButton`
- `fileInfo`, `result`, and `totalProgress` on the hook return — use
  `file`, `file.result`, and `progress`
- `UploadStatusBlock`
- `MultiFileUploadConfig`, `MultiUploadPhase`, `MultiUploadFileState`,
  `MultiUploadHooks`

### Callbacks

Lifecycle hooks always use arrays: `onSuccess(results)`,
`beforeUpload(files)`, `onUploadStart(files)`, `onCancel()`. Per-file:
`onFileSuccess(file, result)`, `onFileProgress`, `onFileError`.
`onError(error, phase)` no longer receives a `File`.

Programmatic upload is `await upload.handleFiles(file)` (`File`, `File[]`,
or `FileList`).
