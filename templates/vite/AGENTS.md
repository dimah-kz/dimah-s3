# dimah-s3

Vite + React starter with [dimah-s3](https://dimah-s3.vercel.app): Hono API via `@dimah-s3/server/hono`, `@dimah-s3/react` for the client, and `@dimah-s3/ui` for upload UI.

Docs: [Quickstart](https://dimah-s3.vercel.app/docs/quickstart) · [Providers](https://dimah-s3.vercel.app/docs/providers)
