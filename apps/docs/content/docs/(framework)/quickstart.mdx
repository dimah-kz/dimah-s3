Create a new app with the CLI, or follow the steps below if you already have a
project. When you are done, picking a file sends it straight to your bucket.

## Create a new project

```npm
npx @dimah-s3/cli@latest create
```

## Manual installation

### Install [step]

```npm
npm i @dimah-s3/server @dimah-s3/react @aws-sdk/client-s3
```

### Server config and route [step]

```dotenv title=".env"
S3_ENDPOINT="https://your-endpoint.example.com"
S3_REGION="auto"
S3_ACCESS_KEY_ID="your-access-key-id"
S3_SECRET_ACCESS_KEY="your-secret-access-key"
S3_BUCKET="your-bucket-name"
```

```ts title="lib/s3.ts"
import { S3Client } from "@aws-sdk/client-s3";
import { dimahS3 } from "@dimah-s3/server";

export const s3Sdk = new S3Client({
  region: process.env.S3_REGION,
  endpoint: process.env.S3_ENDPOINT,
  credentials: {
    accessKeyId: process.env.S3_ACCESS_KEY_ID!,
    secretAccessKey: process.env.S3_SECRET_ACCESS_KEY!,
  },
});

export const s3 = dimahS3({
  client: s3Sdk,
  bucket: process.env.S3_BUCKET!,
  upload: { prefix: "uploads" },
});
```

Any S3-compatible provider works — details in [Providers](/docs/providers).
Cloudflare R2 needs `method: "PUT"` on `upload`.

<Tab value="Vite">

Mount the handler on your Node/Hono API (the Vite starter uses
`@hono/node-server`). Register **PUT** and **PATCH** as well as GET/POST/DELETE.

```ts title="server/index.ts"
import { Hono } from "hono";
import { toHonoHandler } from "@dimah-s3/server/hono";
import { s3 } from "./s3";

const app = new Hono();
app.on(
  ["GET", "POST", "PUT", "PATCH", "DELETE"],
  "/api/s3/*",
  toHonoHandler(s3),
);
```

Point the browser client at that origin with
`createS3Client({ baseURL: "http://127.0.0.1:8787/api/s3" })` when the UI and
API are on different ports.

</Tab>

<Tab value="Express">

Mount **before** `express.json()` so the body is not consumed early.

```ts title="server.ts"
import express from "express";
import { toExpressHandler } from "@dimah-s3/server/express";
import { s3 } from "./s3";

const app = express();
app.all("/api/s3/*", toExpressHandler(s3)); // Express 5: "/api/s3/*splat"
app.use(express.json());
```

</Tab>

### Client [step]

```ts title="lib/s3-client.ts"
"use client";

import { createS3Client } from "@dimah-s3/react";

export const s3Client = createS3Client();

/** Next.js App Router: named Client Component export (not `<s3Client.Provider>`). */
export const S3Provider = s3Client.Provider;
```

`s3Client` _is_ the API (`s3Client.download(key)`), plus `Provider` and
`useApi`. Full options: [Client setup](/docs/react/setup).

### One upload button [step]

Import `UploadButton` from `@dimah-s3/ui`, or from
`@/components/dimah-s3/upload/upload-button` after a registry install.

```tsx title="app/page.tsx"
"use client";

import { UploadButton } from "@dimah-s3/ui";

export default function Page() {
  return <UploadButton />;
}
```

Selecting a file uploads directly to S3. The client default key is
`` `${crypto.randomUUID()}/${file.name}` ``; the server `upload.prefix` in
`lib/s3.ts` scopes it under `uploads/`.

<Callout type="warn">
  The client proposes `key` and may send `bucket`. Config `bucket` is the
  default — a client-sent `bucket` is ignored unless you set `allowClientBucket`
  or `buckets`. Scope keys with `prefix` / `resolveKey`, and reject unauthorized
  work in `upload.guard`.
</Callout>
