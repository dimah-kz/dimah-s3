Scaffold a new app, or add dimah-s3 to an existing one. Either way you end up
with an upload button that sends files straight from the browser to your
bucket.

## Create a new project

```npm
npx @dimah-s3/cli@beta create
```

Fill in the `S3_*` values in `.env`, and allow your app's origin in the bucket
CORS rules ([provider guides](/docs/providers)). The CLI already generated
`DIMAH_S3_SECRET`. See [CLI](/docs/cli) for starters and flags.

## Add to an existing app

You need React 19.2 and Node.js 22 or newer. The UI step also needs Tailwind
CSS v4 and [shadcn](https://ui.shadcn.com/docs/installation). The client
steps show Next.js App Router paths.

### Install the packages [step]

```npm
npm i @dimah-s3/server@beta @dimah-s3/core@beta @dimah-s3/react@beta @fuma-translate/react @aws-sdk/client-s3
```

Keep every `@dimah-s3/*` package on the same version.

### Configure S3 and a route [step]

```dotenv title=".env"
S3_ENDPOINT="https://your-endpoint.example.com"
S3_REGION="auto"
S3_ACCESS_KEY_ID="your-access-key-id"
S3_SECRET_ACCESS_KEY="your-secret-access-key"
S3_BUCKET="your-bucket-name"

# Signs upload tickets. Generate one with: openssl rand -base64 32
DIMAH_S3_SECRET="your-generated-secret"
```

```ts title="lib/s3.ts"
import { S3Client } from "@aws-sdk/client-s3";
import { dimahS3, route } from "@dimah-s3/server";

export const awsS3 = new S3Client({
  region: process.env.S3_REGION,
  endpoint: process.env.S3_ENDPOINT,
  credentials: {
    accessKeyId: process.env.S3_ACCESS_KEY_ID!,
    secretAccessKey: process.env.S3_SECRET_ACCESS_KEY!,
  },
  // Required: the SDK default (WHEN_SUPPORTED) breaks presigned uploads.
  requestChecksumCalculation: "WHEN_REQUIRED",
});

export const s3 = dimahS3({
  client: awsS3,
  bucket: process.env.S3_BUCKET!,
  routes: {
    avatar: route({
      upload: { fileTypes: ["image/*"], maxFileSize: 2 * 1024 * 1024 },
      download: true,
    }),
  },
});
```

`DIMAH_S3_SECRET` must be at least 32 characters and the same on every server
instance. See [Upload tickets](/docs/server/upload-tickets).

### Allow your origin in bucket CORS [step]

The browser uploads straight to the bucket, so the bucket must allow your
app's origin. Follow your provider's guide:
[Amazon S3](/docs/providers/aws-s3),
[Cloudflare R2](/docs/providers/cloudflare-r2),
[MinIO](/docs/providers/minio), or
[ArvanCloud](/docs/providers/arvancloud).

### Mount the route handler [step]

<Tabs items={["Next.js", "Hono", "Express", "SvelteKit"]}>

<Tab value="Next.js">

```ts title="app/api/s3/[...s3]/route.ts"
import { toNextJsHandler } from "@dimah-s3/server/next";
import { s3 } from "@/lib/s3";

export const { GET, POST, PUT, PATCH, DELETE } = toNextJsHandler(s3);
```

</Tab>

<Tab value="Hono">

```ts title="src/index.ts"
import { Hono } from "hono";
import { toHonoHandler } from "@dimah-s3/server/hono";
import { s3 } from "./s3";

const app = new Hono();
app.on(
  ["GET", "POST", "PUT", "PATCH", "DELETE"],
  "/api/s3/*",
  toHonoHandler(s3),
);
```

</Tab>

<Tab value="Express">

```ts title="server.ts"
import express from "express";
import { toExpressHandler } from "@dimah-s3/server/express";
import { s3 } from "./s3";

const app = express();
// Mount before express.json(): the adapter reads the raw body.
app.use("/api/s3", toExpressHandler(s3));
app.use(express.json());
```

</Tab>

<Tab value="SvelteKit">

```ts title="src/routes/api/s3/[...path]/+server.ts"
import { toSvelteKitHandler } from "@dimah-s3/server/svelte-kit";
import { s3 } from "$lib/s3";

const handler = toSvelteKitHandler(s3);
export const GET = handler;
export const POST = handler;
export const PUT = handler;
export const PATCH = handler;
export const DELETE = handler;
```

</Tab>

</Tabs>

Vite, Fastify, Elysia, Node, and other runtimes:
[Server Setup](/docs/server/setup#mount-the-handler).

### Create the client [step]

```ts title="lib/s3-client.ts"
"use client";

import { createS3Client } from "@dimah-s3/react";

export const s3Client = createS3Client();
export const S3Provider = s3Client.Provider;
```

### Add the UI and the provider [step]

```npm
npm i @dimah-s3/ui@beta @base-ui/react class-variance-authority cn lucide-react shadcn tw-animate-css
```

<include>../../_includes/ui/index.mdx#styles</include>

```tsx title="app/layout.tsx"
import { Toaster } from "@dimah-s3/ui"; // [!code ++]
import { S3Provider } from "@/lib/s3-client"; // [!code ++]

export default function RootLayout({
  children,
}: {
  children: React.ReactNode;
}) {
  return (
    <html lang="en">
      <body>
        <S3Provider>{children}</S3Provider> {/* [!code ++] */}
        <Toaster /> {/* [!code ++] */}
      </body>
    </html>
  );
}
```

To copy the component source into your project instead, use the
[shadcn registry](/docs/ui/installation).

### Add an upload button [step]

```tsx title="app/page.tsx"
"use client";

import { useUpload } from "@dimah-s3/react";
import { Upload, UploadToasts, UploadTrigger } from "@dimah-s3/ui";

export default function Page() {
  const upload = useUpload({ route: "avatar" });

  return (
    <>
      <Upload upload={upload}>
        <UploadTrigger />
      </Upload>
      <UploadToasts upload={upload} />
    </>
  );
}
```

Pick a file: the server presigns it, the browser uploads it to your bucket,
and the server confirms it.
