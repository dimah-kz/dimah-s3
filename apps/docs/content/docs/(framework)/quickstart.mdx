Create a new app with the CLI, or follow the steps below if you already have a
project. When you are done, picking a file sends it straight to your bucket.

## Create a new project

```npm
npx @dimah-s3/cli@latest create
```

## Manual installation

### Install [step]

```npm
npm i @dimah-s3/server @dimah-s3/react @aws-sdk/client-s3
```

### S3 client [step]

```dotenv title=".env"
S3_ENDPOINT="https://your-endpoint.example.com"
S3_REGION="auto"
S3_ACCESS_KEY_ID="your-access-key-id"
S3_SECRET_ACCESS_KEY="your-secret-access-key"
S3_DEFAULT_BUCKET="your-bucket-name"
```

```ts title="lib/s3-client.ts"
import { S3Client } from "@aws-sdk/client-s3";

export const s3Client = new S3Client({
  region: process.env.S3_REGION,
  endpoint: process.env.S3_ENDPOINT,
  credentials: {
    accessKeyId: process.env.S3_ACCESS_KEY_ID!,
    secretAccessKey: process.env.S3_SECRET_ACCESS_KEY!,
  },
});

export const defaultBucket = process.env.S3_DEFAULT_BUCKET!;
```

Any S3-compatible provider works — details in [Providers](/docs/providers).

### Server config and route [step]

```ts title="lib/s3.ts"
import { dimahS3 } from "@dimah-s3/server";
import { s3Client, defaultBucket } from "@/lib/s3-client";

export const s3 = dimahS3({
  s3: s3Client,
  defaultBucket,
  upload: { enabled: true },
  download: { enabled: false },
  delete: { enabled: false },
  multipart: { enabled: false },
});
```

### Client provider [step]

```tsx title="components/s3-provider.tsx"
"use client";

import { createS3Client } from "@dimah-s3/react";

export const { api, S3Provider, useApi } = createS3Client();

export function S3ClientProvider({ children }: { children: React.ReactNode }) {
  return <S3Provider>{children}</S3Provider>;
}
```

Full client options: [Client setup](/docs/react/setup).

### One upload button [step]

Import `UploadButton` from `@dimah-s3/ui`, or from
`@/components/dimah-s3/upload/upload-button` after a registry install.

```tsx title="app/page.tsx"
"use client";

import { UploadButton } from "@dimah-s3/ui";

export default function Page() {
  return <UploadButton objectKey="uploads/photo.jpg" />;
}
```

Selecting a file uploads directly to S3.

<Callout type="warn">
  The client sends `objectKey` (and may send `bucket`). For anything beyond a
  demo, scope keys to the signed-in user in `presignGuard`.
</Callout>
