R2 exposes an S3-compatible API, but it is **not** a full Amazon S3 clone. Two differences break a naïve “copy the AWS config” setup:

1. **No Presigned POST** — browser form uploads signed with `createPresignedPost` fail. Use **PUT**.
2. **No object ACL** — `x-amz-acl` / `ACL` are ignored. Public access is a **bucket** (or custom domain) setting.

## Required dimah-s3 config

```ts title="lib/s3.ts"
import { dimahS3 } from "@dimah-s3/server";
import { s3Client, defaultBucket } from "@/lib/s3-client";

export const s3 = dimahS3({
  s3: s3Client,
  defaultBucket,
  upload: {
    enabled: true,
    method: "PUT", // R2 does not support Presigned POST
  },
  download: { enabled: true },
  delete: { enabled: true },
  // GetObjectAcl is not meaningful on R2
  resolveObjectAcl: false,
});
```

Leaving `method` at the default `"POST"` is the most common R2 upload failure with dimah-s3.

## Client

```env title=".env"
R2_ENDPOINT="https://<ACCOUNT_ID>.r2.cloudflarestorage.com"
R2_ACCESS_KEY_ID="your-access-key-id"
R2_SECRET_ACCESS_KEY="your-secret-access-key"
R2_DEFAULT_BUCKET_NAME="your-bucket-name"
```

```ts title="lib/s3-client.ts"
import { S3Client } from "@aws-sdk/client-s3";

export const s3Client = new S3Client({
  region: "auto",
  endpoint: process.env.R2_ENDPOINT!,
  credentials: {
    accessKeyId: process.env.R2_ACCESS_KEY_ID!,
    secretAccessKey: process.env.R2_SECRET_ACCESS_KEY!,
  },
});

export const defaultBucket = process.env.R2_DEFAULT_BUCKET_NAME!;
```

Create **R2 API tokens** with Object Read & Write (and Admin Read if you need bucket listing) in the Cloudflare dashboard. Endpoint format: `https://<ACCOUNT_ID>.r2.cloudflarestorage.com`.

## ACL and public files

Do **not** rely on `acl: "public-read"` for R2. The SDK may accept the header; R2 ignores it.

For public objects:

1. Enable **public access** on the bucket (or attach a **custom domain** / `*.r2.dev` public URL in the dashboard).
2. Serve files via that public base URL, or keep the bucket private and use **presigned download** (`download` feature) for temporary access.

Keep `resolveObjectAcl` off — ACL lookup will not behave like AWS.

## Multipart

Multipart upload is supported. Quirks to remember:

- Non-trailing parts should be the **same size** (R2 enforces uniform part size).
- Incomplete multipart uploads expire (default lifecycle) — abort or purge stale uploads if you track them in [db](/docs/db).

dimah-s3 multipart uses signed **PUT** parts, so it aligns with R2.

## CORS

Configure CORS on the R2 bucket so the browser can `PUT` (and `GET` if you download via the storage origin). Include the headers your signed request uses — typically at least `Content-Type`.

Signed headers must match the actual request; a mismatched `Content-Type` is a frequent 403 cause with PUT.

## Checklist

- [ ] `upload.method: "PUT"`
- [ ] `region: "auto"` + R2 `endpoint`
- [ ] `resolveObjectAcl` left `false`
- [ ] Public access via bucket / custom domain — not object ACL
- [ ] Bucket CORS allows your origin, `PUT`, and required headers

Official compatibility matrix: [R2 S3 API](https://developers.cloudflare.com/r2/api/s3/api/).
