title: Cloudflare R2
description: Connect dimah-s3 to Cloudflare R2 with presigned PUT uploads, bucket CORS from the dashboard, and public URLs.
---

Cloudflare R2 speaks the S3 API with two differences that matter here: it has
no presigned POST, and it ignores object ACLs.

## Server configuration

```dotenv title=".env"
S3_ENDPOINT="https://<ACCOUNT_ID>.r2.cloudflarestorage.com"
S3_REGION="auto"
S3_ACCESS_KEY_ID="your-access-key-id"
S3_SECRET_ACCESS_KEY="your-secret-access-key"
S3_BUCKET="your-bucket-name"
```

The keys come from an R2 API token with **Object Read & Write** permission.

```ts title="lib/s3.ts"
import { S3Client } from "@aws-sdk/client-s3";

export const awsS3 = new S3Client({
  region: process.env.S3_REGION,
  endpoint: process.env.S3_ENDPOINT,
  credentials: {
    accessKeyId: process.env.S3_ACCESS_KEY_ID!,
    secretAccessKey: process.env.S3_SECRET_ACCESS_KEY!,
  },
  // Required: the SDK default (WHEN_SUPPORTED) breaks presigned uploads.
  requestChecksumCalculation: "WHEN_REQUIRED",
});
```

Keep the default `upload.method`, `"PUT"`. A route with `method: "POST"`
presigns fine, then R2 rejects the upload.

## Bucket CORS

Add a CORS policy in the bucket's **Settings** in the R2 dashboard:

```json
[
  {
    "AllowedOrigins": ["https://your-app.example"],
    "AllowedMethods": ["GET", "PUT", "HEAD"],
    "AllowedHeaders": ["*"],
    "ExposeHeaders": ["Content-Disposition", "Content-Encoding"],
    "MaxAgeSeconds": 3000
  }
]
```

[Allow your origin in bucket CORS](/docs/providers#allow-your-origin-in-bucket-cors)
explains each field.

## Public files

`acl: "public-read"` does not make an object public on R2. Turn on the bucket's
public `r2.dev` URL, or connect a custom domain, and use it as the public base:

```dotenv title=".env"
S3_PUBLIC_BASE_URL="https://cdn.example.com"
```

Then build URLs with
[`buildPublicObjectUrl`](/docs/providers#make-files-public). The `r2.dev` URL
is rate-limited, so use a custom domain in production.

Upload failing? See [Troubleshooting](/docs/providers#troubleshooting).
