title: Cloudflare R2
description: Connect dimah-s3 to Cloudflare R2 with presigned PUT uploads, bucket CORS from the dashboard, and public URLs.

Cloudflare R2 speaks the S3 API with two differences that matter here: it has
no presigned POST, and it ignores object ACLs. Keep the default PUT upload
method.

## Settings

| Setting                      | Value                                           |
| ---------------------------- | ----------------------------------------------- |
| `region`                     | `"auto"`                                        |
| `endpoint`                   | `https://<ACCOUNT_ID>.r2.cloudflarestorage.com` |
| `forcePathStyle`             | Leave unset                                     |
| `requestChecksumCalculation` | `"WHEN_REQUIRED"`                               |
| `upload.method`              | `"PUT"` (default). Never `"POST"`               |

## Server configuration

```ts title="lib/s3.ts"
import { S3Client } from "@aws-sdk/client-s3";
import { dimahS3, route } from "@dimah-s3/server";

export const awsS3 = new S3Client({
  region: "auto",
  endpoint: `https://${process.env.R2_ACCOUNT_ID}.r2.cloudflarestorage.com`,
  credentials: {
    accessKeyId: process.env.R2_ACCESS_KEY_ID!,
    secretAccessKey: process.env.R2_SECRET_ACCESS_KEY!,
  },
  requestChecksumCalculation: "WHEN_REQUIRED", // [!code ++]
});

export const s3 = dimahS3({
  client: awsS3,
  bucket: process.env.R2_BUCKET!,
  routes: {
    avatar: route({
      upload: {
        fileTypes: ["image/*"],
        maxFileSize: 2 * 1024 * 1024,
      },
    }),
  },
});
```

## Bucket CORS

Add a CORS policy to the bucket in the Cloudflare R2 dashboard:

```json
[
  {
    "AllowedOrigins": ["https://your-app.example"],
    "AllowedMethods": ["GET", "PUT", "HEAD"],
    "AllowedHeaders": ["*"],
    "ExposeHeaders": ["Content-Disposition", "Content-Encoding"],
    "MaxAgeSeconds": 3000
  }
]
```

[Allow your origin in bucket CORS](/docs/providers#allow-your-origin-in-bucket-cors)
explains each field.

## Provider notes

- **No presigned POST.** Do not set `upload.method: "POST"` on an R2 route.
  The presign succeeds, but R2 rejects the form upload.
- **ACLs are ignored.** `acl: "public-read"` does not make an object public.
- **Public files.** Turn on public access for the bucket, or connect a custom
  domain such as `cdn.example.com`. Build URLs from that base and the
  server-issued key with [`buildPublicObjectUrl`](/docs/core#helpers), which
  encodes the key.

## Troubleshooting

<Accordions>

<Accordion title="Presign succeeds, then the upload fails">

- The route must use `PUT`. Remove `upload.method: "POST"`.
- The bucket's CORS policy must allow your exact origin and `PUT`. A missing
  rule shows up as a network error in the browser.
