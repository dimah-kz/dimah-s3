MinIO is a self-hosted, S3-compatible object store. Point the client at the
MinIO API port, turn on path-style addressing, and allow your app's origin on
the MinIO server.

## Settings

| Setting                      | Value                                              |
| ---------------------------- | -------------------------------------------------- |
| `region`                     | `"us-east-1"`                                      |
| `endpoint`                   | The MinIO API URL, such as `http://localhost:9000` |
| `forcePathStyle`             | `true` for a host-and-port endpoint                |
| `requestChecksumCalculation` | `"WHEN_REQUIRED"`                                  |
| `upload.method`              | `"PUT"` (default) or `"POST"`                      |

## Server configuration

```ts title="lib/s3.ts"
import { S3Client } from "@aws-sdk/client-s3";
import { dimahS3, route } from "@dimah-s3/server";

export const awsS3 = new S3Client({
  region: "us-east-1",
  endpoint: process.env.S3_ENDPOINT || "http://localhost:9000",
  forcePathStyle: true, // [!code ++]
  credentials: {
    accessKeyId: process.env.S3_ACCESS_KEY_ID || "minioadmin",
    secretAccessKey: process.env.S3_SECRET_ACCESS_KEY || "minioadmin",
  },
  requestChecksumCalculation: "WHEN_REQUIRED", // [!code ++]
});

export const s3 = dimahS3({
  client: awsS3,
  bucket: "my-bucket",
  routes: {
    avatar: route({
      upload: {
        fileTypes: ["image/*"],
        maxFileSize: 2 * 1024 * 1024,
      },
    }),
  },
});
```

## Server CORS

MinIO takes its CORS origins from the server environment. Set
`MINIO_API_CORS_ALLOW_ORIGIN` on the MinIO server:

```bash
MINIO_API_CORS_ALLOW_ORIGIN=https://your-app.example
```

## Provider notes

- **Path-style addressing.** With `forcePathStyle: true`, object URLs take the
  form `http://host:9000/bucket/key`. Virtual-hosted bucket URLs also work
  when DNS and TLS are set up for bucket subdomains; then `forcePathStyle` is
  not required.
- **Access.** MinIO grants access with bucket policies, not object ACLs.
- **Local credentials.** The `minioadmin` fallback in the example is for a
  local server only.

## Troubleshooting

<Accordions>

<Accordion title="Browser uploads fail with a network error on localhost">

- `S3_ENDPOINT` must point to the MinIO API port (typically `9000`), not the
  web console port (typically `9001`).
- `MINIO_API_CORS_ALLOW_ORIGIN` must include your app's exact origin.

</Accordion>
