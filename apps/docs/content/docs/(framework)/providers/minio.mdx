MinIO is a self-hosted, S3-compatible object store. Point the client at the
MinIO API port, turn on path-style addressing, and allow your app's origin on
the MinIO server.

## Server configuration

```dotenv title=".env"
S3_ENDPOINT="http://localhost:9000"
S3_REGION="us-east-1"
S3_ACCESS_KEY_ID="minioadmin"
S3_SECRET_ACCESS_KEY="minioadmin"
S3_BUCKET="my-bucket"
```

- `S3_ENDPOINT` is the API port, typically `9000`, not the web console port,
  typically `9001`.
- `minioadmin` is the root login of a local server. Use your own keys anywhere
  else.

```ts title="lib/s3.ts"
import { S3Client } from "@aws-sdk/client-s3";

export const awsS3 = new S3Client({
  region: process.env.S3_REGION,
  endpoint: process.env.S3_ENDPOINT,
  forcePathStyle: true, // [!code highlight]
  credentials: {
    accessKeyId: process.env.S3_ACCESS_KEY_ID!,
    secretAccessKey: process.env.S3_SECRET_ACCESS_KEY!,
  },
  // Required: the SDK default (WHEN_SUPPORTED) breaks presigned uploads.
  requestChecksumCalculation: "WHEN_REQUIRED",
});
```

`forcePathStyle: true` puts the bucket in the path, as in
`http://localhost:9000/my-bucket/key`. A host-and-port endpoint needs it.
Leave it off only when DNS and TLS serve bucket subdomains.

## Server CORS

MinIO takes its CORS origins from the server environment, not from the bucket.
Set `MINIO_API_CORS_ALLOW_ORIGIN` on the MinIO server to a comma-separated list
of your app's exact origins:

```bash
MINIO_API_CORS_ALLOW_ORIGIN=https://your-app.example,http://localhost:3000
```

## Public files

MinIO grants access with bucket policies, not object ACLs. Allow anonymous
reads with a bucket policy, such as `mc anonymous set download local/my-bucket`,
and use the bucket URL as the public base:

```dotenv title=".env"
S3_PUBLIC_BASE_URL="http://localhost:9000/my-bucket"
```

Then build URLs with
[`buildPublicObjectUrl`](/docs/providers#make-files-public).

Upload failing? See [Troubleshooting](/docs/providers#troubleshooting).
