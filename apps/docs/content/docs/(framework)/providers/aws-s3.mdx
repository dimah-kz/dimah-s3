---
title: Amazon S3
description: Connect dimah-s3 to an Amazon S3 bucket, allow browser uploads in bucket CORS, and serve public files.
---

Amazon S3 supports everything dimah-s3 uses: presigned PUT and POST, object
ACLs, SHA-256 checksums, and multipart uploads. Set the region and
credentials, then allow your app's origin in bucket CORS.

## Server configuration

```dotenv title=".env"
S3_REGION="us-east-1"
S3_ACCESS_KEY_ID="your-access-key-id"
S3_SECRET_ACCESS_KEY="your-secret-access-key"
S3_BUCKET="your-bucket-name"
```

Leave `S3_ENDPOINT` unset: the SDK derives the endpoint from the region.

```ts title="lib/s3.ts"
import { S3Client } from "@aws-sdk/client-s3";

export const awsS3 = new S3Client({
  region: process.env.S3_REGION,
  credentials: {
    accessKeyId: process.env.S3_ACCESS_KEY_ID!,
    secretAccessKey: process.env.S3_SECRET_ACCESS_KEY!,
  },
  // Required: the SDK default (WHEN_SUPPORTED) breaks presigned uploads.
  requestChecksumCalculation: "WHEN_REQUIRED",
});
```

Pass it to `dimahS3({ client: awsS3 })`, as in the
[Quickstart](/docs/quickstart#configure-s3-and-a-route-step).

## Bucket CORS

In the S3 console, open the bucket's **Permissions** tab and edit
**Cross-origin resource sharing (CORS)**:

```json
[
  {
    "AllowedOrigins": ["https://your-app.example"],
    "AllowedMethods": ["GET", "PUT", "HEAD"],
    "AllowedHeaders": ["*"],
    "ExposeHeaders": ["Content-Disposition", "Content-Encoding"],
    "MaxAgeSeconds": 3000
  }
]
```

Add `POST` if a route sets `upload.method: "POST"`.
[Allow your origin in bucket CORS](/docs/providers#allow-your-origin-in-bucket-cors)
explains each field.

## Public files

New S3 buckets default to **Bucket owner enforced** Object Ownership, which
turns ACLs off. Keep uploads private on those buckets, and grant public reads
through a bucket policy or CloudFront. Set the public base to the bucket or
CloudFront URL:

```dotenv title=".env"
S3_PUBLIC_BASE_URL="https://your-bucket-name.s3.us-east-1.amazonaws.com"
```

Then build URLs with
[`buildPublicObjectUrl`](/docs/providers#make-files-public). On a bucket with
ACLs on, set `acl: "public-read"` on the route instead.

Upload failing? See [Troubleshooting](/docs/providers#troubleshooting).
