dimah-s3 provides a full-stack file management solution for S3-compatible storage you control — covering server handlers, client hooks, and optional shadcn UI for upload, download, and deletion.

## Feature comparison

| Feature                  |          dimah-s3           | [Better Upload](https://better-upload.com) | [UploadThing](https://uploadthing.com) | [Uppy](https://uppy.io) |
| ------------------------ | :-------------------------: | :----------------------------------------: | :------------------------------------: | :---------------------: |
| **Server handlers**      |          Built-in           |                Uploads only                |              Hosted SaaS               |       None (DIY)        |
| **S3 Storage ownership** |         Your bucket         |                Your bucket                 |             Hosted bucket              |       Your bucket       |
| **Upload lifecycle**     | Presign + HeadObject verify |                  Presign                   |               Hosted API               |       Client-only       |
| **Download & Preview**   |   Presign, Proxy & Inline   |                    DIY                     |              Hosted URLs               |           DIY           |
| **Object Deletion**      | Server-mediated with guards |                    DIY                     |               Hosted API               |           DIY           |
| **Database tracking**    |  Optional (`@dimah-s3/db`)  |                    None                    |            Hosted dashboard            |          None           |
| **Client UI**            |      Headless + shadcn      |              shadcn uploaders              |            React components            |     Dashboard modal     |

---

## Why choose dimah-s3?

- **Unified lifecycle**: Manage upload, download, and delete under cohesive route policies.
- **Server-owned keys**: Prevent key injection and namespace pollution.
- **Verified metadata**: Rely on `HeadObject` for verified sizes and MIME types instead of trusting client claims.
- **Zero lock-in**: Connect any S3-compatible backend (AWS S3, Cloudflare R2, MinIO, Wasabi, ArvanCloud).
