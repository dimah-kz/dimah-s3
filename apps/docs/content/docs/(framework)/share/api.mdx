The reference for [`@dimah-s3/share`](/docs/share). The plugin needs
[`db()`](/docs/db) in the same `plugins` list.

## Policy

Set the rules once in `share()`. A request that breaks one fails with
`VALIDATION_ERROR`, naming the field.

```ts title="lib/s3.ts"
share({
  client: dimahS3Share,
  url: (token) => `${process.env.APP_URL}/s/${token}`,
  // Every link expires within 30 days; one without expiresAt gets 7.
  expiration: { default: 7 * 86_400, max: 30 * 86_400 },
  password: { required: false, minLength: 8 },
  folders: true,
  authorize: ({ action, settings }) =>
    action !== "createLink" || settings?.maxDownloads !== null,
  onDownloaded: ({ link, object }) =>
    audit.log("share.download", link.id, object.key),
});
```

## Authorize and hooks

`authorize` runs for every owner action after the caller's scope is
resolved and the link or its target is known to be theirs, so it can only
narrow access. db's own `authorize` runs before it, with
`operation: "plugin"` and `plugin: { id: "share", action }`. On `listLinks`,
`target` is the object or folder the list is filtered by; without `target`,
the call lists every link of the scope, tokens included.

`authorizeVisit` is the visitor side. It runs on `openLink` once the link is
unlocked, and on `listShared`, `downloadShared`, and `sharedFile`, after the
link is known to open and before anything is counted, listed, or sent. It
sees the link, its target, and the folder or file the call reaches. `false`
answers `SHARE_TARGET_UNAVAILABLE`, the same as a deleted target, so an item
your app hides without deleting it, such as one in its trash, stops opening,
and opens again once it is back:

```ts title="lib/s3.ts"
share({
  client: dimahS3Share,
  authorizeVisit: ({ folder }) => !folder?.path.split("/").includes("Trash"),
});
```

It checks the call, not each row: a folder listing still shows a hidden
subfolder by name, and opening that subfolder is refused.

The hooks run after the action. A throw fails the call, so catch errors in
an analytics hook. Their contexts never carry the password hash.

## Security

- The token has 192 random bits and is stored as is, so the owner can copy a
  link again. Treat the `share_link` table like your session table.
- Passwords are hashed with PBKDF2-SHA256 (600,000 iterations) through Web
  Crypto, so the plugin runs on Node.js and edge runtimes.
- A revoked link stops handing out download URLs at once. A presigned URL
  already handed out works until `downloadExpiresIn` passes.
- A download counts when its URL is handed out, not when the bytes arrive.
  The limit is a compare-and-set, so concurrent downloads never pass it.
- `access` proofs and `/share/file` URLs are signed with the instance secret
  (`DIMAH_S3_SECRET`). Rotating it keeps them valid while the old secret is
  still in the list.

## API Reference

### share()

`share(options)` returns the plugin. It throws at `dimahS3()` without `db()`,
and when a lifetime or a length is not a positive integer.

| Prop                | Type                                                              | Default               | Description                                                                                   |
| ------------------- | ----------------------------------------------------------------- | --------------------- | --------------------------------------------------------------------------------------------- |
| `client`            | `DimahS3ShareClient`                                              | required              | `DimahS3Share.client(adapter)`, with the adapter you give `db()`                              |
| `url`               | `(token) => string`                                               | —                     | The page a visitor opens. Owner responses carry it as `link.url`; without it, `url` is `null` |
| `expiration`        | `{ default?: number \| null; max?: number }`                      | `{ default: 604800 }` | Lifetimes in seconds. `max` makes every link expire and caps `default`                        |
| `password`          | `{ required?: boolean; minLength?: number }`                      | `{ minLength: 8 }`    | Password rules for new and updated links                                                      |
| `folders`           | `boolean`                                                         | `true`                | Allow links to folders                                                                        |
| `downloadExpiresIn` | `number`                                                          | `300`                 | Lifetime of a visitor's download URL in seconds, capped by the route's `maxExpiresIn`         |
| `unlockExpiresIn`   | `number`                                                          | `3600`                | Lifetime of an `access` proof in seconds                                                      |
| `authorize`         | `(context: ShareAuthorizeContext) => boolean \| Promise<boolean>` | —                     | `false` rejects an owner action with `FORBIDDEN`                                              |
| `authorizeVisit`    | `(context: ShareVisitContext) => boolean \| Promise<boolean>`     | —                     | `false` fails a visitor call with `SHARE_TARGET_UNAVAILABLE`                                  |
| `onCreated`         | `(context) => void \| Promise<void>`                              | —                     | After a link is created. Context: `request`, `locals`, `scope`, `link`                        |
| `onUpdated`         | `(context) => void \| Promise<void>`                              | —                     | After a link's settings change. Also `previous`                                               |
| `onRevoked`         | `(context) => void \| Promise<void>`                              | —                     | After a link is revoked                                                                       |
| `onOpened`          | `(context) => void \| Promise<void>`                              | —                     | After a visitor opens an unlocked link. Context: `request`, `locals`, `link`, `target`        |
| `onDownloaded`      | `(context) => void \| Promise<void>`                              | —                     | After a visitor gets a download URL. Context: `request`, `locals`, `link`, `object`           |

### ShareAuthorizeContext

Fields marked `?` are optional.

| Property    | Type                                                                       | Description                                                                                     |
| ----------- | -------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| `action`    | `"createLink" \| "listLinks" \| "getLink" \| "updateLink" \| "revokeLink"` | The owner action                                                                                |
| `scope`     | `string`                                                                   | The caller's db scope                                                                           |
| `request`   | `Request`                                                                  | The request                                                                                     |
| `locals`    | `DimahS3Locals`                                                            | What the guards returned                                                                        |
| `target?`   | `{ type: "object"; object } \| { type: "folder"; folder }`                 | The db row the link points at, while it exists. On `listLinks`, the row the list is filtered by |
| `link?`     | `ShareLink`                                                                | The link as it is, on `getLink`, `updateLink`, and `revokeLink`                                 |
| `settings?` | `{ expiresAt; passwordProtected; maxDownloads; label }`                    | The settings it will have, on `createLink` and `updateLink`                                     |

### ShareVisitContext

| Property  | Type                                                             | Description                                                                                   |
| --------- | ---------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| `action`  | `"openLink" \| "listShared" \| "downloadShared" \| "sharedFile"` | The visitor action                                                                            |
| `link`    | `ShareLink`                                                      | The link, with its `scope`                                                                    |
| `target`  | `{ type: "object"; object } \| { type: "folder"; folder }`       | The db row the link points at                                                                 |
| `folder?` | `StorageFolder`                                                  | The folder `listShared` lists or searches, or the one that holds `object`. Absent at the root |
| `object?` | `StorageObject`                                                  | The file `downloadShared` and `sharedFile` send, or an object link's file                     |
| `request` | `Request`                                                        | The request                                                                                   |
| `locals`  | `DimahS3Locals`                                                  | What the guards returned                                                                      |

### Client actions

`shareClient()` from `@dimah-s3/share/client` puts these on `api.share`.
Each takes `(input, options?)`, with `options` `{ signal, headers }`.

| Action           | Endpoint               | Who     | Returns                      |
| ---------------- | ---------------------- | ------- | ---------------------------- |
| `createLink`     | `POST /share/link`     | Owner   | `{ link: ShareClientLink }`  |
| `listLinks`      | `GET /share/links`     | Owner   | `{ links, nextCursor }`      |
| `getLink`        | `GET /share/link`      | Owner   | `{ link }`                   |
| `updateLink`     | `PATCH /share/link`    | Owner   | `{ link }`                   |
| `revokeLink`     | `DELETE /share/link`   | Owner   | `{ link }`                   |
| `openLink`       | `GET /share/open`      | Visitor | `{ link: ShareVisitorLink }` |
| `unlockLink`     | `POST /share/unlock`   | Visitor | `{ access, expiresAt }`      |
| `listShared`     | `GET /share/items`     | Visitor | `ShareListSharedResponse`    |
| `downloadShared` | `POST /share/download` | Visitor | `ShareDownloadResponse`      |

`GET /share/file` (`sharedFile`) streams a file from a signed URL that
`downloadShared` returns on a proxy route. Guards see every one as
`operation: "plugin"` with `plugin: { id: "share", action }`.
`isSharePublicAction(context)` is true for the visitor actions and
`sharedFile`.

### createLink input

| Prop           | Type                                                               | Default              | Description                                                                       |
| -------------- | ------------------------------------------------------------------ | -------------------- | --------------------------------------------------------------------------------- |
| `target`       | `{ type: "object"; key; bucket? } \| { type: "folder"; folderId }` | required             | What to share. `bucket` only when the routes use several                          |
| `expiresAt`    | `Date \| string \| null`                                           | `expiration.default` | When the link stops opening. `null` never expires, unless `expiration.max` is set |
| `password`     | `string \| null`                                                   | —                    | Visitors enter it first                                                           |
| `maxDownloads` | `number \| null`                                                   | —                    | Downloads the link hands out, 1 to 1,000,000                                      |
| `label`        | `string \| null`                                                   | —                    | Your note. Visitors never see it                                                  |

`updateLink` takes `id` and the same settings. An omitted field stays;
`null` clears a password, an expiry, or a limit. `listLinks` takes
`target`, `includeRevoked`, `limit` (1 to 100), and `cursor`.

### ShareClientLink

| Property            | Type                                                | Description                                                            |
| ------------------- | --------------------------------------------------- | ---------------------------------------------------------------------- |
| `id`                | `string`                                            | The link id                                                            |
| `token`             | `string`                                            | The secret of the link                                                 |
| `url`               | `string \| null`                                    | From the `url` option                                                  |
| `status`            | `"active" \| "expired" \| "revoked" \| "exhausted"` | Whether it opens                                                       |
| `target`            | `{ type; id; name; available; key \| path }`        | The object (`key`) or folder (`path`). `available: false` once deleted |
| `label`             | `string \| null`                                    | Your note                                                              |
| `passwordProtected` | `boolean`                                           | Visitors enter a password first                                        |
| `expiresAt`         | `string \| null`                                    | ISO date                                                               |
| `maxDownloads`      | `number \| null`                                    | The download limit                                                     |
| `downloadCount`     | `number`                                            | Download URLs handed out                                               |
| `viewCount`         | `number`                                            | Unlocked opens. Concurrent opens can miss a count                      |
| `lastAccessedAt`    | `string \| null`                                    | Last open or download                                                  |
| `revokedAt`         | `string \| null`                                    | When it was turned off                                                 |
| `createdAt`         | `string`                                            | ISO date                                                               |
| `updatedAt`         | `string`                                            | ISO date                                                               |

### Visitor inputs and responses

Every visitor input takes `token`, and `access` for an unlocked
password-protected link.

| Action           | Also takes                                      | Response                                                                                                            |
| ---------------- | ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `openLink`       | —                                               | `link`: `type`, `locked`, `passwordProtected`, `expiresAt`, `downloadsLeft`, and `object` or `folder` once unlocked |
| `unlockLink`     | `password`                                      | `access`, `expiresAt`                                                                                               |
| `listShared`     | `folderId`, `search`, `sort`, `limit`, `cursor` | `objects`, `nextCursor`; the first page adds `folders` and `trail`, a search `locations` and `total`                |
| `downloadShared` | `id` (required on a folder link), `disposition` | `url`, `mode`, `expiresIn`, `disposition`, `downloadsLeft`                                                          |

A visitor sees a file as `id`, `name`, `size`, `contentType`, `updatedAt`,
and `folderId`; never its key, route, or scope. `folderId: null` is the top
of the shared folder.

### s3.share

The plugin's context on the server (`SharePluginContext`).

| Property      | Type                                                                        | Description                                                                                                                                         |
| ------------- | --------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| `api`         | `ShareServerApi`                                                            | Every client action as `(input, options?)`, behind the instance guard. `options` is `S3ServerCallOptions`                                           |
| `links`       | `ShareLinks`                                                                | `find`, `findByToken`, `list(scope)`, `count(scope)`, `revoke(id)`, and `revokeTarget(target)`, with no guard                                       |
| `pruneLinks`  | `(options: { olderThan: Date \| number }) => Promise<{ pruned; orphaned }>` | Removes links revoked or expired before `olderThan`, and links created before it whose target was deleted (`orphaned`). Reads every older live link |
| `checkSchema` | `() => Promise<void>`                                                       | Throws unless the database is at share schema `1.0.0`. The first query runs it too                                                                  |

### useShareLinks()

`useShareLinks(api.share, target, options?)` from `@dimah-s3/share/react`
keeps the links of one object or folder in React state, for an owner screen.
`react` is an optional peer of `@dimah-s3/share`, needed only for this entry.
A `null` target waits.

```tsx
"use client";

import { useShareLinks } from "@dimah-s3/share/react";

const api = s3Client.useApi();
const { links, status, create, update, revoke } = useShareLinks(api.share, {
  type: "object",
  key,
});
await create({ maxDownloads: 3 });
```

| Option           | Type      | Default | Description                                                 |
| ---------------- | --------- | ------- | ----------------------------------------------------------- |
| `includeRevoked` | `boolean` | `false` | Also list revoked links, and keep a link once it is revoked |
| `limit`          | `number`  | `100`   | Links per page                                              |

| Property   | Type                                          | Description                                                 |
| ---------- | --------------------------------------------- | ----------------------------------------------------------- |
| `links`    | `ShareClientLink[]`                           | The target's links, newest first                            |
| `status`   | `"idle" \| "loading" \| "success" \| "error"` | `idle` without a target                                     |
| `error`    | `unknown`                                     | What the first page threw, while `status` is `error`        |
| `hasMore`  | `boolean`                                     | Another page follows                                        |
| `loadMore` | `() => Promise<void>`                         | Appends the next page                                       |
| `refresh`  | `() => Promise<void>`                         | Loads the first page again                                  |
| `create`   | `(settings?) => Promise<ShareClientLink>`     | Creates a link to the target and puts it first              |
| `update`   | `(id, settings) => Promise<ShareClientLink>`  | Changes a link's settings                                   |
| `revoke`   | `(id) => Promise<ShareClientLink>`            | Turns a link off; it leaves `links` unless `includeRevoked` |

The mutations reject with the API error, such as `VALIDATION_ERROR`. The
[`ShareLinkDialog`](/docs/ui/components/share-link-dialog) is built on it.

### shareObjectSource()

`shareObjectSource(api.share, { token, access?, limit? })` from
`@dimah-s3/share/client` returns a read-only `useObjectList` source. It
lists one folder per page, searches every folder below the open one, and
maps a file's `objectKey` to its share id.

`downloadSharedFile(api.share, id, { token, access?, disposition?, signal? })`
gets a download URL, navigates to it, and resolves with the `downloadShared`
response, so a page can show the new `downloadsLeft`.

### Errors

| Situation                                                                      | Status | Code                                   |
| ------------------------------------------------------------------------------ | ------ | -------------------------------------- |
| No link has the token, or the owner asked for another scope's                  | `404`  | `SHARE_LINK_NOT_FOUND`                 |
| The link expired                                                               | `410`  | `SHARE_LINK_EXPIRED`                   |
| The owner revoked it                                                           | `410`  | `SHARE_LINK_REVOKED`                   |
| It reached `maxDownloads`                                                      | `410`  | `SHARE_LINK_EXHAUSTED`                 |
| Its file or folder was deleted, its route removed, or `authorizeVisit` refused | `410`  | `SHARE_TARGET_UNAVAILABLE`             |
| A visitor call on a locked link without a valid `access`                       | `401`  | `SHARE_PASSWORD_REQUIRED`              |
| `unlockLink` with the wrong password                                           | `401`  | `SHARE_PASSWORD_INVALID`               |
| A folder link while `folders: false`                                           | `400`  | `SHARE_FOLDER_LINKS_DISABLED`          |
| A forged or expired `/share/file` URL                                          | `403`  | `SHARE_DOWNLOAD_URL_INVALID`           |
| A file or folder id outside the share                                          | `404`  | `OBJECT_NOT_FOUND`, `FOLDER_NOT_FOUND` |
| A route without downloads                                                      | `404`  | `FEATURE_DISABLED`                     |

The `SHARE_*` codes are in the core catalog, `S3_ERROR_CODES` from
`@dimah-s3/core`, so [`useFormatError`](/docs/react/helpers#errors) words
them with the rest, in your `translations`. `SHARE_ERROR_CODES` names the same
entries.

## Frequently asked questions

<Accordions>
<Accordion title="Can I share with another signed-in user instead of a link?">

Not with this plugin. Sharing between accounts needs roles and inheritance
through folders, which depend on your user model. For a team, give its
members one db scope, such as `org:acme`.

</Accordion>
<Accordion title="Does a link follow a file that is replaced?">

Yes, when a route sets `plugins: { db: { replace: "overwrite" } }`: the db
row keeps its id. A file deleted and uploaded again gets a new id, so its
old links stop opening.

</Accordion>
<Accordion title="How do I turn off every link before I hide a file?">

`await s3.share.links.revokeTarget({ type: "object", objectId: object.id })`.

</Accordion>
</Accordions>
