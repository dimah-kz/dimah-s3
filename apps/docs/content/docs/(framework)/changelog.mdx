## 0.8.0

<span className="text-sm text-muted-foreground">
  August 17, 2026 · Minor Release
</span>

This release aligns the server and client API with **Better Auth** and **better-call** patterns for improved developer experience and typed error handling.

<Callout type="info">
  **The core S3 presign protocol is unchanged.** This update focuses on naming
  consistency, DX improvements, and unified error handling across the server and
  client.
</Callout>

### Key Updates

#### Server Configuration

- **Unified config**: Uses `client` (`awsS3`) and `bucket` for default bucket configuration. Client-sent `bucket` values are ignored unless explicitly enabled via `allowClientBucket` or `buckets`.
- **Feature options**: Enable features with a boolean or options object (`upload: { prefix: "uploads" }`). Multipart support is enabled by default when `upload` is on.
- **Guard hooks**: `upload.guard` and `download.guard` replace `presignGuard`. Plain errors thrown in guards return **403**, while errors in lifecycle hooks (`on*`) return **500**.
- **Key scoping**: Custom prefixes and keys are managed via `prefix` or `resolveKey`.

```ts title="lib/s3.ts"
import { S3Client } from "@aws-sdk/client-s3";
import { dimahS3 } from "@dimah-s3/server";

export const awsS3 = new S3Client({/* credentials */});

export const s3 = dimahS3({
  client: awsS3,
  bucket: process.env.S3_BUCKET!,
  upload: {
    prefix: "uploads",
    guard: async ({ key }) => {
      // Auth or quota validation
    },
  },
});
```

#### React Client

- **Direct API object**: `createS3Client()` returns the client instance directly (e.g. `s3Client.download(key)`), along with its bound `Provider` and `useApi`.
- **Download hook**: `useDownload({ mode: "fetch" })` replaces `useFetchDownload` (default mode is `"navigate"`).
- **Typed errors**: Hook error states return `DimahS3Error | null`.

```ts title="lib/s3-client.ts"
import { createS3Client } from "@dimah-s3/react";

export const s3Client = createS3Client();

// Mount provider in your app:
// <s3Client.Provider>{children}</s3Client.Provider>
```

#### HTTP Layer & Error Handling

- **better-call & Zod**: Endpoints and plugins use `createS3Endpoint` with Zod validation. Endpoint calls use object parameters: `s3.api.download({ query: { key } })`.
- **Error model**: `DimahS3Error` extends better-call's `APIError`. The JSON error body follows `{ message, code?, params? }` and can be checked with `isDimahS3Error` or `isAPIError`.
- **Client error mapping**: Browser client maps non-OK responses onto `DimahS3Error` and exposes `$ERROR_CODES`.

#### Plugins

- **Author helpers**: Utilities like `chainHooks` and hook context types are exported from `@dimah-s3/server/plugins`.
- **Absolute paths**: Plugin endpoints use absolute paths under `basePath` (`/db/objects`), with client plugins using `getActions($fetch)` and `pluginPath`.

### Migration Reference

| Previous (0.7.x)                               | Current (0.8.x)                                   |
| :--------------------------------------------- | :------------------------------------------------ |
| `s3: awsClient`                                | `client: awsS3`                                   |
| `defaultBucket`                                | `bucket`                                          |
| `upload: { enabled: true }`                    | `upload: true` or `upload: { prefix: "uploads" }` |
| `upload.presignGuard`                          | `upload.guard`                                    |
| `download.presignGuard`                        | `download.guard`                                  |
| `useFetchDownload`                             | `useDownload({ mode: "fetch" })`                  |
| `const { api, S3Provider } = createS3Client()` | `const s3Client = createS3Client()`               |
| `s3.api.download(key)`                         | `s3.api.download({ query: { key } })`             |
| `S3_DEFAULT_BUCKET`                            | `S3_BUCKET`                                       |
