## Server

With the plugin registered, use `s3.db.objects` in routes, quota checks, or jobs:

```ts
const objects = await s3.db.objects.listByScope({ scope, limit: 50 });
const usage = await s3.db.objects.getScopeUsage(scope);
```

| Method                 | Use for                                             |
| ---------------------- | --------------------------------------------------- |
| `listByScope`          | List files for a scope (skips `deleted` by default) |
| `countByScope`         | Count with the same filters as `listByScope`        |
| `getScopeUsage`        | Total bytes and object count — quota checks         |
| `find` / `findActive`  | Load one file by `bucket` + `key`                   |
| `findPendingMultipart` | Lookup for multipart resume                         |

To remove a file, use [`api.delete`](/docs/react) — not store helpers. The plugin updates the database in its delete hook ([Setup](/docs/db/setup#delete-behavior)).

## Browser

Add `dbClient()` to `createS3Client` — no extra app route:

```ts
import { createS3Client } from "@dimah-s3/react";
import { dbClient } from "@dimah-s3/db/client";

export const { api, S3Provider, useApi } = createS3Client({
  basePath: "/api/s3",
  plugins: [dbClient()],
});
```

List the signed-in user's files:

```ts
const { scope, usage, objects } = await api.db.listObjects({ limit: 50 });

await api.download(objects[0].key, { bucket: objects[0].bucket });
```

`listObjects` returns `{ scope, usage, objects }` for the caller's scope. Each item includes `bucket`, `key`, `filename`, `contentType`, `size`, `status`, and `createdAt` — enough to drive a file list and wire download / delete.

Optional filters: `status`, `limit`, `offset`.

## Quota

Quotas are app-owned. Check usage in your upload guard:

```ts
const s3 = dimahS3({
  plugins: [db({ client: dimahS3Db, resolveScope })],
  upload: {
    enabled: true,
    presignGuard: async ({ request, fileSize }) => {
      const scope = await resolveScope(request);
      const { totalBytes } = await s3.db.objects.getScopeUsage(scope!);
      if (totalBytes + (fileSize ?? 0) > MAX_BYTES) {
        throw forbidden("Quota exceeded");
      }
    },
  },
});
```

Use `chainHooks` from `@dimah-s3/server` when you need plugin ownership checks and your own policy on the same feature.

## Custom access

When same-scope is not enough — for example public files — build a guard with `createObjectAccessGuard`:

```ts
createObjectAccessGuard({
  db: dimahS3Db,
  resolveScope,
  authorize: (object, { scope }) =>
    object.scope === scope || object.metadata?.visibility === "public",
});
```
