[`@dimah-s3/server`](https://www.npmjs.com/package/@dimah-s3/server) is the
backend for dimah-s3. It signs short-lived URLs, runs your hooks, and never
touches the file bytes — the browser talks to the bucket directly.

<Flow
  label="Presign-first"
  steps={[

    { name: "S3", kind: "s3", note: "bytes stay here" },
  ]}
/>

It is not an S3 SDK wrapper. List, copy, tagging, and other operations stay in
your code with the
[AWS SDK](https://www.npmjs.com/package/@aws-sdk/client-s3). Export that
instance as `s3Sdk` from `lib/s3.ts` and pass `client: s3Sdk` into
`dimahS3`.

## What you get

- **One instance** — `dimahS3()` gives an HTTP `handler` and a typed `api`
- **Lifecycle hooks** — auth, quotas, and DB writes at each step
- **Verified uploads** — `HeadObject` before you trust size or type
- **Any runtime** — adapters for Next.js, Express, Hono, and others, or a
  plain `Request` / `Response` handler
