[`@dimah-s3/server`](https://www.npmjs.com/package/@dimah-s3/server) is the backend engine for dimah-s3. It manages signed URLs, enforces route constraints, authorizes requests through guards, and triggers lifecycle callbacks.

## Server architecture

- **Upload & Download**: Presigned URLs (direct client-to-bucket transfer).
- **Deletion**: Handled securely on the server via `DeleteObjectCommand`.

---

## Core capabilities

- **Single configuration**: `dimahS3()` exports both an HTTP route `handler` and a direct typed server `api`.
- **Lifecycle hooks**: Inject auth, database logging, or quota checks at presign, confirmation, and deletion.
- **HeadObject verification**: Real file sizes and MIME headers are confirmed from S3 before committing to databases.
- **Zero-dependency adapters**: Built-in handlers for Next.js, Hono, Express, Fastify, SvelteKit, Elysia, and standard Fetch.

Yes. Use `s3.api` (e.g. `s3.api.download({ query: { route: 'avatar', key } })` or `s3.put({ route: 'avatar', ... })`).
