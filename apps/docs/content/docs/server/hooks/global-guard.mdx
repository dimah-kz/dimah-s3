---
title: Global Guard
description: Request-level policy that runs before every operation.
---

`guard` lives on `dimahS3()`. It
runs first on every request, including plugin endpoints. There is no
`enabled` flag.

Use it for the caller: session, auth, tenancy, whether the request is
allowed at all. It only sees `{ request }` — the route name is not
available yet (lookup happens next). Per-object rules belong on the
feature hooks — those receive `key` and `bucket`.

If some routes are public and others need a session, put auth on
`route.guard` (or the feature `guard`) instead of the instance `guard`.

Throw to reject. A plain `Error` becomes `403`. Use `DimahS3Error` or
[`errors`](/docs/server/errors) for other codes.

```ts title="lib/s3.ts"
import { S3Client } from "@aws-sdk/client-s3";
import { dimahS3, errors, route } from "@dimah-s3/server";

export const awsS3 = new S3Client({/* env */});

export const s3 = dimahS3({
  client: awsS3,
  bucket: process.env.S3_BUCKET!,
  guard: async ({ request }) => {
    const session = await getSession(request);
    if (!session) throw errors.unauthorized();
  },
  routes: {
    uploads: route({ upload: true }),
  },
});
```
