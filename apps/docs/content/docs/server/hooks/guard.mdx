---
title: Guard
description: Auth hook that runs on every request.
---

`guard` runs first on every operation — upload, download, delete, multipart,
and plugin endpoints. There is no `enabled` flag.

Throw to reject. The default status is `403`. Use `DimahS3Error` for other
codes.

```ts title="lib/s3.ts"
import { dimahS3, DimahS3Error } from "@dimah-s3/server";
import { s3Client, defaultBucket } from "@/lib/s3-client";

export const s3 = dimahS3({
  s3: s3Client,
  defaultBucket,
  guard: async ({ request }) => {
    const session = await getSession(request);
    if (!session) throw new DimahS3Error("Unauthorized", 401);
  },
  upload: { enabled: true },
});
```

Per-file checks belong on the feature hooks (`upload.presignGuard`,
`download.presignGuard`, `delete.guard`) — they receive `key` and `bucket`.

Plugin guards run first. See [hook order](/docs/server/plugins#hook-order).
