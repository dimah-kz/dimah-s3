---
title: Download
description: Authorize before issuing a GET URL — presign or same-origin proxy.
---

Enable with `download: true` or an options object on a
[named route](/docs/server/routes). The default is a short-lived S3 GET
URL. Set `download.mode: "proxy"` to stream bytes through `GET /file`
instead (private buckets without CORS, or when the client must not hit
storage directly).

A download-only route is the usual shape. If these keys were created by
an upload route, enable `download` on **that** route instead of a second
name for the same prefix
([combining features](/docs/server/routes#combining-features)).

The stored `key` must sit under the route `keyPrefix`. That is a folder
bound, not ownership — add `guard` or [`db()`](/docs/db) so callers cannot
download another user's object in the same prefix.

`disposition` defaults to `"attachment"`. Use `"inline"` for preview
(`<img>`, `<video>`, `useObjectUrl`). `download.resolve` can change
`fileName`, `disposition`, and `expiresIn` per request.

```ts title="lib/s3.ts"
import { S3Client } from "@aws-sdk/client-s3";
import { dimahS3, errors, route } from "@dimah-s3/server";

export const awsS3 = new S3Client({/* env */});

export const s3 = dimahS3({
  client: awsS3,
  bucket: process.env.S3_BUCKET!,
  routes: {
    uploads: route({
      download: {
        disposition: "inline",
        guard: async ({ key, request }) => {
          if (!request.headers.get("authorization")) {
            throw errors.unauthorized();
          }
        },
      },
    }),
  },
});
```

`onPresigned` receives the same fields plus `url` and `expiresIn`
(`0` when `mode` is `"proxy"`).
