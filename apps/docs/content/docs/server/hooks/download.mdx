---
title: Download
description: Authorize before issuing a presigned GET URL.
---

Enable with `download: { enabled: true }`.

**Flow:** `presignGuard` → `onPresigned`

The server never streams the file. It signs a short-lived GET URL; the
browser fetches from S3. `onPresigned` receives the same fields plus `url`
and `expiresIn`.

```ts title="lib/s3.ts"
import { dimahS3, DimahS3Error } from "@dimah-s3/server";
import { s3Client, defaultBucket } from "@/lib/s3-client";

export const s3 = dimahS3({
  s3: s3Client,
  defaultBucket,
  download: {
    enabled: true,
    presignGuard: async ({ key, request }) => {
      if (!(await canRead(request, key))) {
        throw new DimahS3Error("Forbidden", 403);
      }
    },
  },
});
```

| Hook           | When                     |
| -------------- | ------------------------ |
| `presignGuard` | Before the URL is signed |
| `onPresigned`  | After the URL is issued  |
