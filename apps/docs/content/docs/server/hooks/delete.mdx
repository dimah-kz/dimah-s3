---
title: Delete
description: Authorize deletion and run cleanup after S3 removes the object.
---

Enable with `delete: { enabled: true }`.

**Flow:** `guard` → S3 `DeleteObject` → `onDeleted`

```ts title="lib/s3.ts"
import { dimahS3, DimahS3Error } from "@dimah-s3/server";
import { s3Client, defaultBucket } from "@/lib/s3-client";

export const s3 = dimahS3({
  s3: s3Client,
  defaultBucket,
  delete: {
    enabled: true,
    guard: async ({ key, request }) => {
      if (!(await canDelete(request, key))) {
        throw new DimahS3Error("Forbidden", 403);
      }
    },
    onDeleted: async ({ key }) => {
      await removeObjectRow(key);
    },
  },
});
```

`onDeleted` runs after S3 has removed the object — same `{ key, bucket,
request }`. Use it for DB cleanup, not as a substitute for deleting from
the bucket.

| Hook        | When                     |
| ----------- | ------------------------ |
| `guard`     | Before `DeleteObject`    |
| `onDeleted` | After the object is gone |
