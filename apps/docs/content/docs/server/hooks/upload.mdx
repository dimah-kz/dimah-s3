---
title: Upload
description: Presign, confirm, and persist verified metadata.
---

Enable with `upload: { enabled: true }`. Default method is `"POST"`. Use
`"PUT"` when the provider has no Presigned POST
([Cloudflare R2](/docs/providers/cloudflare-r2)).

<Flow
  label="Upload flow"
  steps={[
    { name: "presignGuard", kind: "hook" },
    { name: "onPresigned", kind: "hook" },
    { name: "Upload", kind: "s3" },
    { name: "confirmGuard", kind: "hook" },
    { name: "HeadObject", kind: "server" },
    { name: "onConfirmed", kind: "hook" },
  ]}
/>

```ts title="lib/s3.ts"
import { dimahS3, DimahS3Error } from "@dimah-s3/server";
import { s3Client, defaultBucket } from "@/lib/s3-client";

export const s3 = dimahS3({
  s3: s3Client,
  defaultBucket,
  upload: {
    enabled: true,
    presignGuard: async ({ fileSize }) => {
      if (fileSize && fileSize > 10 * 1024 * 1024) {
        throw new DimahS3Error("File too large", 413);
      }
    },
    onConfirmed: async ({ key, contentLength }) => {
      // persist { key, size: contentLength }
    },
  },
});
```

<Callout>
  `fileSize` / `contentType` on presign are what the client sent. `onConfirmed`
  sees `HeadObject` — use that for quotas and records.
</Callout>

Set `requireFileSize: true` to reject presign requests that omit `fileSize`.
