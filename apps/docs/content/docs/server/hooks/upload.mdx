---
title: Upload
description: Presign, confirm, and persist verified metadata.
---

Enable on a [named route](/docs/server/routes) with `upload: true` or an
options object. Upload is **off** until you set it. Leave download and
delete off unless this route also serves those objects
([one job per route](/docs/server/routes#one-job-per-route)). Default method
is `"POST"`. Use `"PUT"` when the provider has no Presigned POST
([Cloudflare R2](/docs/providers/cloudflare-r2)). Multipart is **off**
until you set `upload.multipart: true`.

Simple uploads finish with **`confirm`**. Multipart finishes with
**`multipart.complete`** — there is no second `confirm`. Both run
`upload.confirmGuard` then `upload.onConfirmed`. See
[Multipart](/docs/server/hooks/multipart) and [Security](/docs/server/security).

```ts title="lib/s3.ts"
import { S3Client } from "@aws-sdk/client-s3";
import { dimahS3, route } from "@dimah-s3/server";

export const awsS3 = new S3Client({/* env */});

export const s3 = dimahS3({
  client: awsS3,
  bucket: process.env.S3_BUCKET!,
  routes: {
    uploads: route({
      upload: {
        fileTypes: ["image/*", "application/pdf"],
        maxFileSize: 10 * 1024 * 1024,
        onConfirmed: async ({ key, contentLength }) => {
          // persist { key, size: contentLength }
        },
      },
    }),
  },
});
```

<Callout>
  `fileSize` / `contentType` on presign are what the client sent. `onConfirmed`
  sees `HeadObject` — use that for quotas and records. Route `fileTypes` /
  `maxFileSize` are enforced at both steps. `fileTypes` is the stored MIME
  header and filename, not a byte sniff.
</Callout>

<Callout type="warn">
  The client does not send a key on upload. The server generates `{keyPrefix}/
  {uuid}/{name}` (`keyPrefix` defaults to the route name) unless `upload.object`
  returns `folder` or `key` — those are nested under `keyPrefix`. Object ACL is
  `private` unless you set `upload.acl` or return one from `object`. A plain
  `Error` from `object` is **403**.
</Callout>

## Guard

Runs **after** `upload.object` assigns a key (and after instance / route
`guard`), on single-shot presign and multipart init. Throw to reject. A
plain `Error` becomes **403**. Put auth that must run before key generation
on instance `guard` or `route.guard`.

## On confirmed

Runs after `HeadObject` on confirm and multipart complete. Use
`contentLength` and verified type here — not the presign body. Multipart
adds `uploadId`.
