---
title: Upload
description: Presign, confirm, and persist verified metadata.
---

Enable with `upload: { enabled: true }`. Default method is `"POST"`. Use
`"PUT"` when the provider has no Presigned POST
([Cloudflare R2](/docs/providers/cloudflare-r2)).

**Flow:** `presignGuard` → `onPresigned` → client uploads to S3 →
`confirmGuard` → `onConfirmed`

```ts title="lib/s3.ts"
import { dimahS3, DimahS3Error } from "@dimah-s3/server";
import { s3Client, defaultBucket } from "@/lib/s3-client";

export const s3 = dimahS3({
  s3: s3Client,
  defaultBucket,
  upload: {
    enabled: true,
    presignGuard: async ({ fileSize }) => {
      if (fileSize && fileSize > 10 * 1024 * 1024) {
        throw new DimahS3Error("File too large", 413);
      }
    },
    onConfirmed: async ({ key, contentLength, contentType }) => {
      await saveObject({ key, size: contentLength, contentType });
    },
  },
});
```

`fileSize`, `contentType`, and `metadata` on presign are **client-declared**.
`onConfirmed` receives `HeadObject` values — trust those for quotas and DB
writes.

Set `requireFileSize: true` to reject presign requests that omit `fileSize`.

| Hook           | When                         |
| -------------- | ---------------------------- |
| `presignGuard` | Before the URL is signed     |
| `onPresigned`  | After the URL is issued      |
| `confirmGuard` | Before `HeadObject`          |
| `onConfirmed`  | After the object is verified |
