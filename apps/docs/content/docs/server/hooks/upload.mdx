---
title: Upload
description: Presign, confirm, and persist verified metadata.
---

Enable with `upload: true` or an options object. Default method is `"POST"`.
Use `"PUT"` when the provider has no Presigned POST
([Cloudflare R2](/docs/providers/cloudflare-r2)). Multipart is included unless
you set `multipart: false`.

```ts title="lib/s3.ts"
import { S3Client } from "@aws-sdk/client-s3";
import { dimahS3, DimahS3Error } from "@dimah-s3/server";

export const awsS3 = new S3Client({/* env */});

export const s3 = dimahS3({
  client: awsS3,
  bucket: process.env.S3_BUCKET!,
  upload: {
    prefix: "uploads",
    guard: async ({ fileSize }) => {
      if (fileSize && fileSize > 10 * 1024 * 1024) {
        throw new DimahS3Error("PAYLOAD_TOO_LARGE", {
          message: "File too large",
        });
      }
    },
    onConfirmed: async ({ key, contentLength }) => {
      // persist { key, size: contentLength }
    },
  },
});
```

<Callout>
  `fileSize` / `contentType` on presign are what the client sent. `onConfirmed`
  sees `HeadObject` — use that for quotas and records.
</Callout>

<Callout type="warn">
  Treat `key` as untrusted. Rewrite it with `prefix` or `resolveKey`, then
  reject unauthorized uploads in `guard`. How `bucket` is resolved is in [Server
  setup](/docs/server/setup).
</Callout>

Set `requireFileSize: true` to reject presign requests that omit `fileSize`.

## Guard

Runs before the URL is signed. Throw to reject. A plain `Error` becomes
**403**.

## On confirmed

Runs after `HeadObject`. This is the safe place to persist metadata. A
plain `Error` here becomes **500**.
