---
title: Multipart
description: Lifecycle hooks for large-file uploads.
---

Enable with `multipart: true`, or omit it — multipart is on whenever `upload`
is on unless you set `multipart: false`. Pair it with client `multipart`
options — see [Upload](/docs/react/hooks/upload).

Multipart **complete** is the confirmation step (HeadObject after S3
assembles the parts). There is no extra `confirm` call. Persist in
`onComplete` the same way you persist in `upload.onConfirmed`.

Abort is a separate path: `abortGuard` → `onAbort`. Listing parts:
`listGuard` → `onList`.

```ts title="lib/s3.ts"
import { S3Client } from "@aws-sdk/client-s3";
import { dimahS3, DimahS3Error } from "@dimah-s3/server";

export const awsS3 = new S3Client({/* env */});

export const s3 = dimahS3({
  client: awsS3,
  bucket: process.env.S3_BUCKET!,
  upload: { prefix: "uploads" },
  multipart: {
    initGuard: async ({ fileSize }) => {
      if (fileSize && fileSize > 5 * 1024 * 1024 * 1024) {
        throw new DimahS3Error("PAYLOAD_TOO_LARGE", {
          message: "File too large",
        });
      }
    },
    onComplete: async ({ key, contentLength }) => {
      // persist { key, size: contentLength }
    },
    onAbort: async ({ key, uploadId }) => {
      // drop any pending row for `{ key, uploadId }`
    },
  },
});
```

<Callout>
  `fileSize` on init is what the client sent. `contentLength` on `onComplete`
  comes from `HeadObject`.
</Callout>

Set `requireFileSize: true` to reject init without `fileSize`. ACL follows
the same rules as upload (`acl` / `allowClientAcl`, inherited from upload
when omitted).

The complete body only sends `partNumber`s. The server lists parts from S3
for ETags and rejects a missing part with `MULTIPART_PART_MISSING`.

<Accordion title="Other hooks">

| Hook            | When                 | Extra                     |
| --------------- | -------------------- | ------------------------- |
| `onInit`        | After init           | `uploadId`                |
| `partGuard`     | Before each part URL | `partNumber`, `partSize?` |
| `completeGuard` | Before complete      | `parts`                   |
| `abortGuard`    | Before abort         | `uploadId`                |
| `onAbort`       | After abort          | `uploadId`                |
| `listGuard`     | Before listing parts | `uploadId`                |
| `onList`        | After listing parts  | `parts`                   |
