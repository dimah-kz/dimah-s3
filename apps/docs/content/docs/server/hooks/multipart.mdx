---
title: Multipart
description: Lifecycle hooks for large-file uploads.
---

Enable with `multipart: { enabled: true }`. Pair it with client
`multipart` options — see [Upload](/docs/react/hooks/upload).

**Flow:** `initGuard` → `onInit` → `partGuard` (per part) → `completeGuard`
→ `onComplete`. Abort is a separate path: `abortGuard` → `onAbort`.

```ts title="lib/s3.ts"
import { dimahS3, DimahS3Error } from "@dimah-s3/server";
import { s3Client, defaultBucket } from "@/lib/s3-client";

export const s3 = dimahS3({
  s3: s3Client,
  defaultBucket,
  multipart: {
    enabled: true,
    initGuard: async ({ fileSize }) => {
      if (fileSize && fileSize > 5 * 1024 * 1024 * 1024) {
        throw new DimahS3Error("File too large", 413);
      }
    },
    onComplete: async ({ key, contentLength, eTag }) => {
      await saveObject({ key, size: contentLength, eTag });
    },
    onAbort: async ({ key, uploadId }) => {
      await discardUpload({ key, uploadId });
    },
  },
});
```

`fileSize` on init is client-declared. `contentLength` on `onComplete` is
verified by S3. Set `requireFileSize: true` to reject init without
`fileSize`.

| Hook            | When                           | Extra context                         |
| --------------- | ------------------------------ | ------------------------------------- |
| `initGuard`     | Before `CreateMultipartUpload` | `fileSize?`                           |
| `onInit`        | After init                     | `uploadId`                            |
| `partGuard`     | Before each part presign       | `uploadId`, `partNumber`, `partSize?` |
| `completeGuard` | Before complete                | `uploadId`, `parts`                   |
| `onComplete`    | After the object is verified   | `contentLength`, `eTag`, …            |
| `abortGuard`    | Before abort                   | `uploadId`                            |
| `onAbort`       | After abort                    | `uploadId`                            |
| `listGuard`     | Before listing parts           | `uploadId`                            |
| `onList`        | After listing parts            | `uploadId`, `parts`                   |
