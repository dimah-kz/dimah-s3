## List your plugin

Open a pull request that adds a row to the Community table on this page
(`apps/docs/content/docs/server/community-plugins.mdx`). A listed plugin:

- Is published to npm as `dimah-s3-<name>` or `@scope/dimah-s3-<name>`, with
  the keyword `dimah-s3-plugin`.
- Lists `@dimah-s3/server` and `@dimah-s3/core` as `peerDependencies`.
- Puts every endpoint under its id, and prefixes its error codes with it.
- Has a README with setup and the routes options it reads.

Plugins in this table are maintained by their authors. Review a plugin's
hooks before you add it: they run inside every upload, download, and
delete.
