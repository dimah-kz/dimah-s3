Let an owner share a file or folder from your file browser. `ShareLinkDialog`
creates [share links](/docs/share) with a lifetime, an optional password,
download limit, and note, copies them, and lists the links the item already
has, with their status, downloads, and views. It needs `share()` on the server
and `shareClient()` on the client.

## Usage

Open it from a row of [`ObjectList`](/docs/ui/components/object-list):
`shareTargetOf` turns a row into the link's target.

```tsx title="components/file-manager.tsx"
"use client";

import { dbObjectSource, type DbClientObject } from "@dimah-s3/db/client";
import { useObjectList, type ObjectListEntry } from "@dimah-s3/react";
import {
  ObjectList,
  ObjectListContent,
  ObjectListEntryMenu,
} from "@dimah-s3/ui";
import { ShareLinkDialog, shareTargetOf } from "@dimah-s3/ui/share";
import { Share2 } from "lucide-react";
import { useState } from "react";
import { s3Client } from "@/lib/s3-client";

export function FileManager() {
  const api = s3Client.useApi();
  const list = useObjectList({
    ...dbObjectSource(api.db, { route: "files" }),
    queryKey: ["files"],
  });
  const [sharing, setSharing] = useState<ObjectListEntry<DbClientObject>>();

  return (
    <>
      <ObjectList
        list={list}
        renderActions={(entry) => (
          <ObjectListEntryMenu
            actions={[
              {
                label: "Share",
                icon: <Share2 />,
                onClick: () => setSharing(entry),
              },
            ]}
          />
        )}
      >
        <ObjectListContent />
      </ObjectList>
      <ShareLinkDialog
        share={api.share}
        target={sharing ? shareTargetOf(sharing) : null}
        name={sharing?.name}
        open={sharing !== undefined}
        onOpenChange={(open) => {
          if (!open) setSharing(undefined);
        }}
      />
    </>
  );
}
```

The dialog loads the links each time it opens. Every call runs as the
signed-in owner, so your `share({ authorize })` decides what they may do.

## Links

- **Create link** creates a link with the form's settings and copies its URL.
  The URL is `link.url`, from `share({ url })`. Without it, pass `linkUrl`.
- **Copy link** copies the URL again.
- **Change link** edits the lifetime, password, download limit, and note.
  An empty password field keeps the current password.
- **Turn off link** revokes it, after a confirmation. A revoked link leaves
  the list.

`expiryOptions` sets the lifetimes the form offers, in seconds. Add `null`
for a link that never expires, unless `share()` sets `expiration.max`. An
error from the server, such as a lifetime past that maximum, shows under the
form through [`useFormatError`](/docs/react/helpers#errors).

## Accessibility

- The dialog is labelled by its title and described by its description.
- Each form field has a label. Errors are announced with `role="alert"`.
- The row buttons are named: "Copy link", "Change link", "Turn off link".

## API Reference

### ShareLinkDialog

| Prop            | Type                                                              | Default                    | Description                                                      |
| --------------- | ----------------------------------------------------------------- | -------------------------- | ---------------------------------------------------------------- |
| `share`         | `ShareLinksActions`                                               | required                   | `api.share` from a client with `shareClient()`                   |
| `target`        | `ShareTargetInput \| null`                                        | required                   | The object or folder whose links it shows                        |
| `open`          | `boolean`                                                         | required                   | Whether the dialog is open                                       |
| `onOpenChange`  | `(open: boolean) => void`                                         | required                   | Runs when the dialog asks to open or close                       |
| `name`          | `string`                                                          | —                          | The item's name, for the title                                   |
| `expiryOptions` | `readonly (number \| null)[]`                                     | `[86400, 604800, 2592000]` | Lifetimes a new link can pick, in seconds; the first is selected |
| `linkUrl`       | `(token: string) => string`                                       | —                          | A link's URL when `share()` has no `url`                         |
| `fields`        | `{ password?: boolean; maxDownloads?: boolean; label?: boolean }` | all on                     | Turn off an optional field                                       |

### shareTargetOf()

`shareTargetOf(entry, { bucket? })` returns the `ShareTargetInput` of an
`ObjectList` row: `{ type: "object", key }` for a file, by its object key, and
`{ type: "folder", folderId }` for a folder. Pass `bucket` when the routes use
several buckets.

### useShareLinks()

The dialog runs on `useShareLinks` from `@dimah-s3/share/react`. Use the hook
for a screen of your own: see the [Share API](/docs/share/api#usesharelinks).
