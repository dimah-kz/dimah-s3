A profile picture or logo that the user can replace. `AvatarUpload` shows the
stored image; a click or a drop uploads a new one, with a progress ring over
the preview.

## Usage

```tsx
"use client";

import { useUpload } from "@dimah-s3/react";
import { AvatarUpload, UploadToasts } from "@dimah-s3/ui";

export function ProfilePhoto({
  avatarKey,
  saveAvatar,
}: {
  avatarKey: string | null;
  saveAvatar: (key: string) => void;
}) {
  const upload = useUpload({ route: "avatar", accept: ["image/*"] });

  return (
    <>
      <AvatarUpload
        upload={upload}
        route="avatar"
        objectKey={avatarKey}
        label="Change profile photo"
        onUploaded={(result) => saveAvatar(result.key)}
      />
      <UploadToasts upload={upload} />
    </>
  );
}
```

Save `result.key` in `onUploaded`, and pass it back as `objectKey`. `route` is
the route that signs the image URL, usually the one the hook uploads to.

## Examples

### Sizes and shapes

`size` sets the width and height in pixels. `shape="square"` rounds the
corners instead of the whole image, for logos and covers.

## What it shows

1. While an image uploads, and after it succeeds: the picked file's preview.
2. Otherwise: the image at `objectKey`, signed through `route` with
   [`ObjectImage`](/docs/ui/components/object-image).
3. Without a key, or when the image fails to load: a placeholder icon.

The button is disabled while the hook is (`useUpload({ disabled: true })`).

## Without a provider

`AvatarUpload` signs the image URL with the API from `S3Provider`. Without a
provider, pass the same `api` to the hook and to the component:

```tsx
const upload = useUpload({ api, route: "avatar" });

<AvatarUpload
  api={api}
  upload={upload}
  route="avatar"
  objectKey={avatarKey}
  label="Change profile photo"
/>;
```

## Accessibility

- `label` is required: it is the button's accessible name.
- A polite live region announces the upload: preparing, uploading, complete,
  the error, or why a file was rejected.
- While an `UploadToasts` for the same hook is mounted, the toasts announce
  instead, so nothing is read out twice.

## API Reference

| Prop         | Type                             | Default    | Description                                                   |
| ------------ | -------------------------------- | ---------- | ------------------------------------------------------------- |
| `upload`     | `UseUploadReturn`                | required   | The `useUpload` return that uploads the picked image          |
| `route`      | `string`                         | required   | Route that signs the image URL for `objectKey`                |
| `label`      | `string`                         | required   | Accessible name of the button, such as "Change profile photo" |
| `objectKey`  | `string \| null`                 | —          | Key of the current image. Without one, a placeholder shows    |
| `onUploaded` | `(result: UploadResult) => void` | —          | Runs once for each image that uploads                         |
| `size`       | `number`                         | `96`       | Width and height in pixels                                    |
| `shape`      | `"circle" \| "square"`           | `"circle"` | Round image, or rounded corners for logos and covers          |
| `api`        | `S3Api`                          | —          | Signs the image URL. Optional inside `S3Provider`             |
| `className`  | `string`                         | —          | Classes for the button                                        |
