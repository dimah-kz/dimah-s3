Show an image from a private bucket. `ObjectImage` signs an inline URL with
[`useObjectUrl`](/docs/react/hooks/object-url), refreshes it before it
expires, and shares it with other images of the same object.

## Usage

```tsx
"use client";

import { ObjectImage } from "@dimah-s3/ui";

export function CoverImage({ coverKey }: { coverKey: string | null }) {
  return (
    <ObjectImage
      route="covers"
      objectKey={coverKey}
      alt="Album cover"
      className="size-40 rounded-md object-cover"
      fallback={<div className="bg-muted size-40 rounded-md" />}
    />
  );
}
```

`route` must allow downloads. Its server
[download hooks](/docs/server/hooks/download) decide who may read the object,
as for any download.

## Fallback

`fallback` renders in place of the image:

- while there is no key,
- while the URL is being signed,
- when signing fails,
- and when the image fails to load.

It defaults to nothing. A failed image is not signed again until the next
refresh. Your `onError` still runs.

## Accessibility

`alt` is required. Pass `alt=""` when the image is decorative, such as next to
a name that already describes it.

## API Reference

Also accepts every `img` prop except `src`.

| Prop        | Type             | Default  | Description                                           |
| ----------- | ---------------- | -------- | ----------------------------------------------------- |
| `route`     | `string`         | required | Route that signs the URL                              |
| `objectKey` | `string \| null` | required | Key of the stored object. `null` shows `fallback`     |
| `alt`       | `string`         | required | Alternative text. `""` for a decorative image         |
| `fallback`  | `ReactNode`      | —        | Shown while there is no URL, and when the image fails |
| `api`       | `S3Api`          | —        | Signs the URL. Optional inside `S3Provider`           |
