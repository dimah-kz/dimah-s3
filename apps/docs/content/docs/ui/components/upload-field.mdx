Add file uploads to a form. Each file that uploads through `UploadField` adds
its object key to the field's value, and every key submits as a hidden
`<input name>`. Put the [Upload](/docs/ui/components/upload) parts inside it.

## Usage

```tsx
"use client";

import { useUpload } from "@dimah-s3/react";
import {
  UploadDropzone,
  UploadField,
  UploadFieldValue,
  UploadToasts,
} from "@dimah-s3/ui";

export function TicketForm({
  save,
}: {
  save: (formData: FormData) => void | Promise<void>;
}) {
  const upload = useUpload({ route: "attachments", maxFiles: 5 });

  return (
    <form action={save} className="space-y-4">
      <UploadField upload={upload} name="attachments" maxFiles={5}>
        <UploadDropzone />
        <UploadFieldValue />
      </UploadField>
      <UploadToasts upload={upload} />
      <button type="submit">Send</button>
    </form>
  );
}
```

Files in flight show in the dropzone. Once a file uploads it moves to
`UploadFieldValue`, which lists the keys the field holds. On the server, read
them with `formData.getAll("attachments")`.

<Callout type="warn">
  `maxFiles` and the value are client-side. Check the keys, their count, and who
  owns them in your own endpoint. See [Forms](/docs/react/forms).
</Callout>

## Anatomy

```tsx
<UploadField upload={upload} name="attachments">
  <UploadTrigger /> {/* or UploadDropzone */}
  <UploadStatus />
  <UploadFieldValue />
</UploadField>
```

`UploadField` is an [`Upload`](/docs/ui/components/upload) root, so every
upload part works inside it. Inside the field, `UploadStatus` and
`UploadFileList` show only files in flight or failed; uploaded files show in
`UploadFieldValue`.

### Controlled value

Keep the keys in your own state with `value` and `onValueChange`.

```tsx
const [keys, setKeys] = useState<string[]>(post.attachmentKeys);

<UploadField
  upload={upload}
  name="attachments"
  value={keys}
  onValueChange={setKeys}
>
  <UploadTrigger />
  <UploadFieldValue />
</UploadField>;
```

### Custom value rows

Pass a function to `UploadFieldValue` to render each key.

```tsx
function AttachmentNames() {
  const { remove } = useUploadFieldContext();

  return (
    <UploadFieldValue>
      {(item) => (
        <span>
          {item.fileName}
          <button type="button" onClick={() => remove(item.key)}>
            Remove
          </button>
        </span>
      )}
    </UploadFieldValue>
  );
}
```

## Value

- A file adds its key once it uploads. Failed, cancelled, and in-flight files
  add nothing.
- The value grows across picks. The field's own calls always append, so a new
  pick never cancels files still uploading.
- Removing a key from the value does not delete the stored object.
- Keys the field did not upload, such as a `defaultValue`, show the last
  segment of the key as their name.
- `onValueChange` runs after an upload adds a key or `remove` drops one.

## Limit

With `maxFiles`, each call takes only the files that still fit: `maxFiles`
minus the keys in the value and the files still uploading. The hook rejects
the rest with `TOO_MANY_FILES`.

The field sets the limit on the hook itself, with
[`useUploadLimit`](/docs/react/hooks/upload#limit-across-calls), so it also
holds for calls outside the field: a toast's retry, `usePasteFiles`, or your
own `upload.open()`. Those calls follow the hook's `append` option, so pass
`append: true` to `useUpload` when other code uploads through it.

A full field renders its triggers and retry actions focusable but
`aria-disabled`, and drops and pastes do nothing. Read
`useUploadContext().isFull` to show your own hint:

```tsx
function FullHint() {
  const { isFull } = useUploadContext();
  return isFull ? <p>Remove a file to add another.</p> : null;
}
```

## Form reset

An uncontrolled field restores `defaultValue` when its form resets, including
React 19's automatic reset after a `<form action>`, and reports it through
`onValueChange`. Call `upload.reset()` to clear the status too. A controlled
field resets `value` itself.

## API Reference

### UploadField

| Prop            | Type                       | Default  | Description                                                   |
| --------------- | -------------------------- | -------- | ------------------------------------------------------------- |
| `upload`        | `UseUploadReturn`          | required | The `useUpload` return whose uploads fill the field           |
| `name`          | `string`                   | required | Form field name. Each key submits as its own hidden input     |
| `value`         | `readonly string[]`        | —        | Object keys, when you control the value                       |
| `defaultValue`  | `readonly string[]`        | —        | Object keys to start with, when the field keeps its own value |
| `onValueChange` | `(keys: string[]) => void` | —        | Runs with the new keys after one is added or removed          |
| `maxFiles`      | `number`                   | —        | Most keys the field holds, across every call on the hook      |
| `children`      | `ReactNode`                | required | Upload parts and `UploadFieldValue`                           |

### UploadFieldValue

Also accepts every `ul` prop except `children`.

| Prop       | Type                                   | Default                        | Description     |
| ---------- | -------------------------------------- | ------------------------------ | --------------- |
| `children` | `(item: UploadFieldItem) => ReactNode` | File card with a remove action | Renders one key |

### useUploadFieldContext

Returns the field's state inside `UploadField`.

| Property    | Type                         | Description                                                     |
| ----------- | ---------------------------- | --------------------------------------------------------------- |
| `name`      | `string`                     | The field name                                                  |
| `value`     | `readonly string[]`          | The keys                                                        |
| `items`     | `readonly UploadFieldItem[]` | The keys with `fileName`, `fileSize`, `contentType`, and `file` |
| `remaining` | `number \| null`             | Files that still fit, or `null` without `maxFiles`              |
| `remove`    | `(key: string) => void`      | Drops a key from the value. The stored object is kept           |
