`download` presigns a GET. The hook opens that URL — your backend never
streams the file.

The payload is a single object: `route`, `key`, and optional `fileName`.

## Example

Add this to the [`defineApi`](/docs/react/custom-backend) skeleton.
[`@dimah-s3/server`](/docs/server) uses
`GET /api/s3/presign/download?route=…&key=…`.

```ts
async download(payload) {
  const params = new URLSearchParams({
    route: payload.route,
    key: payload.key,
  });
  if (payload.fileName) params.set("fileName", payload.fileName);

  const res = await fetch(`/api/files/presign/download?${params}`);
  if (!res.ok) throw new Error(await res.text());
  return res.json();
}
```
