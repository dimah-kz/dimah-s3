---
title: Download
description: Return a signed or proxied GET URL from a custom backend, for downloads and object previews.
---

`download` returns a GET URL for one object. The default is a short-lived S3
URL with `mode: "presign"`. A backend that streams the body itself returns a
same-origin URL with `mode: "proxy"`.

```ts title="lib/s3-api/download.ts"
import type {
  DownloadPayload,
  DownloadPresignResponse,
  S3RequestOptions,
} from "@dimah-s3/core";
import { $fetch, call } from "./fetch";

export const download = (
  payload: DownloadPayload,
  options?: S3RequestOptions,
) =>
  $fetch<DownloadPresignResponse>("/download", {
    method: "GET",
    query: payload,
    ...call(options),
  });
```

[`@dimah-s3/server`](/docs/server) uses
`GET /api/s3/presign/download?route=…&key=…`. `$fetch` and `call` come from
the [skeleton](/docs/react/custom-backend#skeleton).

## Payload

Fields marked `?` are optional.

| Property       | Type                       | Description                                                                  |
| -------------- | -------------------------- | ---------------------------------------------------------------------------- |
| `route`        | `string`                   | Named route                                                                  |
| `key`          | `string`                   | Object key                                                                   |
| `name?`        | `string`                   | File name for `Content-Disposition`                                          |
| `disposition?` | `"inline" \| "attachment"` | Requested `Content-Disposition`                                              |
| `expiresIn?`   | `number`                   | Requested lifetime in seconds. Sign the shorter of this and your route's cap |

## Response

Return the `disposition` you signed. In presign mode, return the `expiresIn`
you actually signed: [`useObjectUrl`](/docs/react/hooks/object-url) uses it to
refresh the URL before it expires. Leave it out in proxy mode.

| Property      | Type                       | Description                                                |
| ------------- | -------------------------- | ---------------------------------------------------------- |
| `key`         | `string`                   | Object key                                                 |
| `bucket`      | `string`                   | Target bucket                                              |
| `disposition` | `"inline" \| "attachment"` | `Content-Disposition` on the signed or proxied GET         |
| `mode`        | `"presign" \| "proxy"`     | A signed S3 URL, or a same-origin URL your backend streams |
| `url`         | `string`                   | The URL the browser fetches                                |
| `expiresIn`   | `number`                   | `presign` only. URL lifetime in seconds                    |
