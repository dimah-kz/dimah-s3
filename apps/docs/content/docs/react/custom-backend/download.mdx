`download` presigns a GET. The hook opens that URL — your backend never
streams the file.

First argument is `key`; second is optional `options`.

## Example

Add this to the [`defineApi`](/docs/react/custom-backend) skeleton.
[`@dimah-s3/server`](/docs/server) uses `GET /api/s3/presign/download?key=…`.

```ts
async download(key, options) {
  const params = new URLSearchParams({ key });
  if (options?.bucket) params.set("bucket", options.bucket);
  if (options?.fileName) params.set("fileName", options.fileName);

  const res = await fetch(`/api/files/presign/download?${params}`);
  if (!res.ok) throw new Error(await res.text());
  return res.json();
}
```
