`delete` removes one object. Unlike upload and download, this is a direct
mutation — not a presigned client-to-S3 call.

First argument is `key`; second is optional `options`.

## Example

Add this to the [`defineApi`](/docs/react/custom-backend) skeleton.
[`@dimah-s3/server`](/docs/server) uses `DELETE /api/s3/delete?key=…`.

```ts
async delete(key, options) {
  const params = new URLSearchParams({ key });
  if (options?.bucket) params.set("bucket", options.bucket);

  const res = await fetch(`/api/files/delete?${params}`, { method: "DELETE" });
  if (!res.ok) throw new Error(await res.text());
  return res.json();
}
```
