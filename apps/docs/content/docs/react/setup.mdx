Create the client once, mount `S3Provider` near the root, then call any hook
with a route name from your server config.

## Installation

```npm
npm i @dimah-s3/react@beta @dimah-s3/core@beta @fuma-translate/react
```

`@dimah-s3/core` and `@fuma-translate/react` are peer dependencies. Keep
`@dimah-s3/core` on the same version as `@dimah-s3/react`.

### Requirements

- **React 19.2** or newer.
- **Node.js 22** or newer for server rendering and builds.
- **Browsers from Baseline 2024**: Chrome 119, Firefox 124, Safari 17.4, and
  newer. Older browsers lack `Promise.withResolvers` and `AbortSignal.any`,
  and fail on the first upload, download, or delete.

## 1. Create the client

```ts title="lib/s3-client.ts"
"use client";

import { createS3Client } from "@dimah-s3/react";

export const s3Client = createS3Client();
export const S3Provider = s3Client.Provider;
```

The client calls `/api/s3`, the server's default `basePath`. For another path
or origin, cross-origin cookies, or an auth header, pass the
[`createS3Client` options](#creates3client).

With a backend other than `@dimah-s3/server`, pass your own `S3Api` to
`S3Provider` as `api`. See [Bring Your Own Backend](/docs/react/custom-backend).

## 2. Mount S3Provider

```tsx title="app/layout.tsx"
import { S3Provider } from "@/lib/s3-client"; // [!code ++]

export default function RootLayout({
  children,
}: {
  children: React.ReactNode;
}) {
  return (
    <html lang="en">
      <body>
        {/* [!code ++] */}
        <S3Provider>{children}</S3Provider>
      </body>
    </html>
  );
}
```

In Vite or another client-only app, wrap `<App />` in `src/main.tsx` the same
way. For `translations` and `locale`, see
[Internationalization](/docs/i18n).

## 3. Call your first hook

```tsx title="app/file-uploader.tsx"
"use client";

import { useUpload } from "@dimah-s3/react";

export function FileUploader() {
  const upload = useUpload({ route: "avatar" });

  return (
    <div
      {...upload.getRootProps({
        className: "cursor-pointer rounded border p-4 text-center",
      })}
    >
      <input {...upload.getInputProps()} />
      {upload.isPending
        ? `Uploading: ${upload.progress.percent}%`
        : "Click or drop a file here"}
    </div>
  );
}
```

## TypeScript route inference

Declare your server's route names once. `route` then autocompletes in every
hook and component, and an unknown name is a type error:

```ts title="lib/s3-routes.ts"
import type { InferS3Routes } from "@dimah-s3/core";
import type { s3 } from "@/lib/s3";

declare module "@dimah-s3/core" {
  interface DimahS3Routes extends Record<InferS3Routes<typeof s3>, true> {}
}
```

## Plugin error messages

Every catalog code has a translated message. A plugin's own codes show the
English message the server sent. Word them with `formatError` on the
provider: [`useFormatError`](/docs/react/helpers) and every UI toast ask it
first, and `undefined` keeps the built-in message.

```tsx title="app/providers.tsx"
import { isS3ErrorCode } from "@dimah-s3/core";
import type { S3ErrorFormatter } from "@dimah-s3/react";
import { AUDIT_ERROR_CODES } from "@acme/dimah-s3-audit/client";

const formatError: S3ErrorFormatter = (error) => {
  if (isS3ErrorCode(error, AUDIT_ERROR_CODES.AUDIT_ROUTE_UNTRACKED)) {
    return `"${error.params.route}" has no audit log`;
  }
  return undefined;
};

<s3Client.Provider formatError={formatError}>{children}</s3Client.Provider>;
```

Define it outside the component, or memoize it, so it keeps its identity.

## API Reference

### createS3Client

`createS3Client(options?)` takes the same options as `createS3Client` from
`@dimah-s3/core`.

| Prop          | Type                                                       | Default        | Description                                                                              |
| ------------- | ---------------------------------------------------------- | -------------- | ---------------------------------------------------------------------------------------- |
| `basePath`    | `string`                                                   | `"/api/s3"`    | API path prefix. Must match the server `basePath`                                        |
| `baseURL`     | `string`                                                   | —              | Absolute origin and path, such as `https://api.example.com/api/s3`. Wins over `basePath` |
| `credentials` | `RequestCredentials`                                       | —              | Fetch credentials mode, such as `"include"` to send cookies cross-origin                 |
| `headers`     | `HeadersInit \| () => HeadersInit \| Promise<HeadersInit>` | —              | Static headers, or a function called per request. Per-call headers win                   |
| `fetch`       | `(input, init) => Promise<Response>`                       | global `fetch` | Replaces the transport, for SSR, tests, or logging                                       |
| `plugins`     | `S3ClientPlugin[]`                                         | —              | Client plugins, such as `dbClient()` from `@dimah-s3/db/client`                          |

It returns the API object itself:

| Property                | Type            | Description                                                           |
| ----------------------- | --------------- | --------------------------------------------------------------------- |
| `upload`, `download`, … | `S3Api` methods | The API every hook calls. Each takes `(payload, { signal, headers })` |
| `Provider`              | `ComponentType` | `S3Provider` bound to this client. Takes every prop but `api`         |
| `useApi`                | `() => client`  | Reads the provider's API, typed with the client's plugins             |
| `[plugin id]`           | plugin methods  | One object per plugin, such as `db` for `dbClient()`                  |

### S3Provider

| Prop           | Type                             | Default  | Description                                                                                                 |
| -------------- | -------------------------------- | -------- | ----------------------------------------------------------------------------------------------------------- |
| `api`          | `S3Api`                          | required | The API the hooks and components below use                                                                  |
| `translations` | `Partial<Translations>`          | —        | Translated strings. Omit for English                                                                        |
| `locale`       | `string`                         | —        | BCP 47 locale for sizes and counts, such as `"fa"`. Omit for Latin digits                                   |
| `formatError`  | `(error) => string \| undefined` | —        | Your message for an API error, before the built-in one. See [plugin error messages](#plugin-error-messages) |
| `children`     | `ReactNode`                      | required | Your app                                                                                                    |

### useS3Api

`useS3Api()` returns the `S3Api` of the nearest `S3Provider`, to call it
yourself. It throws when no provider is mounted. With client plugins, call
`s3Client.useApi()` instead, which is typed with them.

## Frequently asked questions

<Accordions>

<Accordion title="How do I send auth tokens or cookies?">

Pass `headers`, a value or an async function, or `credentials: "include"`:

```ts title="lib/s3-client.ts"
export const s3Client = createS3Client({
  credentials: "include",
  headers: async () => ({
    Authorization: `Bearer ${await getAuthToken()}`,
  }),
});
```

</Accordion>

<Accordion title="How do I test components that use the hooks?">

Swap what talks to the network, so a test needs no S3 and no server:

- `createS3Client({ fetch })` answers every API call. Return the JSON your server sends.
- [`uploadTransport`](/docs/react/custom-backend#upload-transport) on the API replaces the transfer of single-shot uploads.
- `createMemoryUploadStore()` replaces `localStorage` for [resumable uploads](/docs/react/upload-store).
- `api` on any hook replaces the provider's. `defineApi` type-checks a fake one.

To test server routes without HTTP, call
[`s3.api`](/docs/server/setup#server-side-api-s3api) in process.

</Accordion>

</Accordions>
