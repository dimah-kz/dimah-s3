## Install

```npm
npm i @dimah-s3/react
```

### API client [step]

Hooks only need an `S3Api`. Use `createS3Client` from `@dimah-s3/react` with
`@dimah-s3/server`, or `defineApi` with your own backend.

<Tabs items={["@dimah-s3/server", "Your own backend"]}>

<Tab value="@dimah-s3/server">

If the server is mounted at `/api/s3` ([Server setup](/docs/server/setup)):

```ts title="lib/s3-client.ts"
"use client";

import { createS3Client } from "@dimah-s3/react";

export const s3Client = createS3Client();

/** Next.js App Router: named Client Component export (not `<s3Client.Provider>`). */
export const S3Provider = s3Client.Provider;
```

Custom base path, absolute `baseURL`, plugins, or auth:

```ts
import { createS3Client } from "@dimah-s3/react";
import { dbClient } from "@dimah-s3/db/client";

export const s3Client = createS3Client({
  basePath: "/api/your-path",
  // baseURL: "https://api.example.com/api/s3",
  plugins: [dbClient()],
  credentials: "include",
  headers: async () => ({
    Authorization: `Bearer ${await getAccessToken()}`,
  }),
});
```

`basePath` must match the server. `baseURL` wins when both are set (Vite /
Hono when the UI origin differs). Failed API calls throw `DimahS3Error`
(`.code`, `.status` / `.statusCode`). The client also exposes `$ERROR_CODES`,
`$fetch`, and `$Infer`. Call `s3Client.download({ route, key })` directly, or
`s3Client.useApi()` inside React.

</Tab>

<Tab value="Your own backend">

Implement `S3Api` with `defineApi` and pass it to `S3Provider`. Payload
shapes: [Bring your own backend](/docs/react/custom-backend).

```tsx title="components/s3-provider.tsx"
"use client";

import { S3Provider } from "@dimah-s3/react";
import { api } from "@/lib/s3-api";

export function AppS3Provider({ children }: { children: React.ReactNode }) {
  return <S3Provider api={api}>{children}</S3Provider>;
}
```

</Tab>

</Tabs>

### Provider [step]

Mount once near the app root. Hooks inside can omit `api`.

<Tabs items={["Next.js (App Router)", "Vite / other React apps"]}>

<Tab value="Next.js (App Router)">

```tsx title="app/layout.tsx"
import { S3Provider } from "@/lib/s3-client";

export default function RootLayout({
  children,
}: {
  children: React.ReactNode;
}) {
  return (
    <html lang="en">
      <body>
        <S3Provider>{children}</S3Provider>
      </body>
    </html>
  );
}
```

App Router cannot render `<s3Client.Provider>` from a Server Component. Re-export `S3Provider` from `s3-client.ts` as in the client snippet above.

</Tab>

<Tab value="Vite / other React apps">

```tsx title="src/main.tsx"
import React from "react";
import ReactDOM from "react-dom/client";
import { s3Client } from "./lib/s3-client";
import { App } from "./app";

ReactDOM.createRoot(document.getElementById("root")!).render(
  <React.StrictMode>
    <s3Client.Provider>
      <App />
    </s3Client.Provider>
  </React.StrictMode>,
);
```

</Tab>

</Tabs>

Strings default to English. To localize, pass `translations` on the
provider — [Internationalization](/docs/i18n).

### First hook [step]

Every hook needs a **route name** that matches `dimahS3({ routes })`. The
server generates the object key — do not pass `objectKey` on upload.
Omit `accept` / `maxFileSize` so the hook fills them from
[`api.catalog()`](/docs/server/routes).

```tsx title="app/uploader.tsx"
"use client";

import { useUpload } from "@dimah-s3/react";

export function Uploader() {
  const upload = useUpload({
    route: "uploads",
  });

  return (
    <div {...upload.getRootProps()}>
      <input {...upload.getInputProps()} />
      {upload.isUploading
        ? `${upload.progress.percent}%`
        : "Drop a file or click to upload"}
    </div>
  );
}
```

Need a finished button instead? [Upload Button](/docs/react/ui/components/upload-button).

### Typed routes [step]

`route` is `S3RouteName` — a `string` until you augment `DimahS3Routes`.
Point that interface at your server instance so a typo is a type error:

```ts title="lib/s3-routes.ts"
import type { InferS3Routes } from "@dimah-s3/core";
import type { s3 } from "@/lib/s3";

declare module "@dimah-s3/core" {
  interface DimahS3Routes extends Record<InferS3Routes<typeof s3>, true> {}
}
```

Keep this file on both the server and the client (or in a shared types
package) so hooks and `s3.put` see the same names.
