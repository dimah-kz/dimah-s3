Set up the React client once per app: create an API client, mount
`S3Provider` near the root, then call any hook with a route name from your
server config.

## Installation

```npm
npm i @dimah-s3/react@beta @dimah-s3/core@beta @fuma-translate/react
```

`@dimah-s3/core` (`APIError` and the protocol helpers) and
`@fuma-translate/react` (translated strings) are peer dependencies. Keep
`@dimah-s3/core` on the same version as `@dimah-s3/react`.

### Requirements

- **React 19.2** or newer.
- **Node.js 22** or newer for server rendering and builds.
- **Browsers from Baseline 2024**: Chrome 119, Firefox 124, Safari 17.4, and
  newer. The hooks use `Promise.withResolvers` and `AbortSignal.any`, so an
  older browser fails on the first upload, download, or delete.

## 1. Create the client

<Tabs items={["@dimah-s3/server", "Bring your own backend"]}>

<Tab value="@dimah-s3/server">

`createS3Client` returns the API object, plus a bound `Provider` and a typed
`useApi`.

```ts title="lib/s3-client.ts"
"use client";

import { createS3Client } from "@dimah-s3/react";

export const s3Client = createS3Client();
export const S3Provider = s3Client.Provider;
```

To change the base path, send cookies, or add an auth header:

```ts title="lib/s3-client.ts"
export const s3Client = createS3Client({
  basePath: "/api/s3", // [!code ++]
  credentials: "include", // [!code ++]
  headers: async () => ({
    // [!code ++]
    Authorization: `Bearer ${await getAuthToken()}`, // [!code ++]
  }), // [!code ++]
});
```

</Tab>

<Tab value="Bring your own backend">

Implement `S3Api` with `defineApi` from the engine entry, then pass it to
`S3Provider`:

```tsx title="components/s3-provider.tsx"
"use client";

import { S3Provider } from "@dimah-s3/react";
import { api } from "@/lib/s3-api";

export function AppS3Provider({ children }: { children: React.ReactNode }) {
  return <S3Provider api={api}>{children}</S3Provider>;
}
```

See [Bring Your Own Backend](/docs/react/custom-backend) for the contract.

## 2. Mount S3Provider

Mount the provider near your app root:

<Tabs items={["Next.js (App Router)", "Vite / SPA"]}>

<Tab value="Next.js (App Router)">

```tsx title="app/layout.tsx"
import { S3Provider } from "@/lib/s3-client"; // [!code ++]

export default function RootLayout({
  children,
}: {
  children: React.ReactNode;
}) {
  return (
    <html lang="en">
      <body>
        {/* [!code ++] */}
        <S3Provider>{children}</S3Provider>
      </body>
    </html>
  );
}
```

</Tab>

<Tab value="Vite / SPA">

```tsx title="src/main.tsx"
import React from "react";
import ReactDOM from "react-dom/client";
import { S3Provider } from "./lib/s3-client"; // [!code ++]
import { App } from "./app";

ReactDOM.createRoot(document.getElementById("root")!).render(
  <React.StrictMode>
    {/* [!code ++] */}
    <S3Provider>
      <App />
    </S3Provider>
  </React.StrictMode>,
);
```

## 3. Call your first hook

Pass a route name from your server config:

```tsx title="app/file-uploader.tsx"
"use client";

import { useUpload } from "@dimah-s3/react";

export function FileUploader() {
  const upload = useUpload({ route: "avatar" });

  return (
    <div
      {...upload.getRootProps({
        className: "cursor-pointer rounded border p-4 text-center",
      })}
    >
      <input {...upload.getInputProps()} />
      {upload.isPending
        ? `Uploading: ${upload.progress.percent}%`
        : "Click or drop a file here"}
    </div>
  );
}
```

Every hook takes an optional `api` that replaces the provider's.

## Call the API directly

Read the API from the provider to call it yourself:

- `s3Client.useApi()` is typed with the client's plugins.
- `useS3Api()` from `@dimah-s3/react` returns whatever `S3Provider` holds, for a custom backend or a shared component. It throws when no provider is mounted.

```tsx
import { useS3Api } from "@dimah-s3/react";

const api = useS3Api();
const { url } = await api.download({ route: "avatar", key });
```

## Shared and server modules

The root entry is a client module. Plain functions that do not need React,
such as `defineApi`, `memoryObjectSource`, and
`createLocalStorageUploadStore`, ship from `@dimah-s3/react/engine`, which has
no `"use client"` directive:

```ts title="lib/s3-api.ts"
import { defineApi } from "@dimah-s3/react/engine";
```

See [Engine](/docs/react/guides/engine) for the full list.

## TypeScript route inference

Type route names across hooks and components:

```ts title="lib/s3-routes.ts"
import type { InferS3Routes } from "@dimah-s3/core";
import type { s3 } from "@/lib/s3";

declare module "@dimah-s3/core" {
  // [!code ++]
  interface DimahS3Routes extends Record<InferS3Routes<typeof s3>, true> {} // [!code ++]
}
```

## Testing

Each piece that talks to the network can be swapped, so a test needs no S3
and no server:

| Swap                                                             | Replaces                                                                |
| ---------------------------------------------------------------- | ----------------------------------------------------------------------- |
| `createS3Client({ fetch })`                                      | The transport of every API call. Answer with the JSON your server sends |
| [`uploadTransport`](/docs/react/custom-backend#upload-transport) | The PUT or POST to the presigned URL for single-shot uploads            |
| `createMemoryUploadStore()`                                      | `localStorage` for [resumable uploads](/docs/react/upload-store)        |
| `api` on any hook                                                | The provider's API. `defineApi` type-checks a fake one                  |

On the server, call the instance in process. `s3.api` runs the same guards
and hooks as the HTTP handler, and `locals` seeds what your guards would have
set:

```ts
const presigned = await s3.api.upload(
  { route: "avatar", name: "a.png", size: 1024, type: "image/png" },
  { locals: { userId: "user_1" } },
);
```

## API Reference

### createS3Client

`createS3Client(options?)` takes the same options as `createS3Client` from
`@dimah-s3/core`.

| Prop          | Type                                                       | Default        | Description                                                                              |
| ------------- | ---------------------------------------------------------- | -------------- | ---------------------------------------------------------------------------------------- |
| `basePath`    | `string`                                                   | `"/api/s3"`    | API path prefix. Must match the server `basePath`                                        |
| `baseURL`     | `string`                                                   | —              | Absolute origin and path, such as `https://api.example.com/api/s3`. Wins over `basePath` |
| `credentials` | `RequestCredentials`                                       | —              | Fetch credentials mode, such as `"include"` to send cookies cross-origin                 |
| `headers`     | `HeadersInit \| () => HeadersInit \| Promise<HeadersInit>` | —              | Static headers, or a function called per request. Per-call headers win                   |
| `fetch`       | `(input, init) => Promise<Response>`                       | global `fetch` | Replaces the transport, for SSR, tests, or logging                                       |
| `plugins`     | `S3ClientPlugin[]`                                         | —              | Client plugins, such as `dbClient()` from `@dimah-s3/db/client`                          |

It returns the API object itself:

| Property                | Type            | Description                                                           |
| ----------------------- | --------------- | --------------------------------------------------------------------- |
| `upload`, `download`, … | `S3Api` methods | The API every hook calls. Each takes `(payload, { signal, headers })` |
| `Provider`              | `ComponentType` | `S3Provider` bound to this client. Takes every prop but `api`         |
| `useApi`                | `() => client`  | Reads the provider's API, typed with the client's plugins             |
| `[plugin id]`           | plugin methods  | One object per plugin, such as `db` for `dbClient()`                  |

### S3Provider

| Prop           | Type                    | Default  | Description                                                               |
| -------------- | ----------------------- | -------- | ------------------------------------------------------------------------- |
| `api`          | `S3Api`                 | required | The API the hooks and components below use                                |
| `translations` | `Partial<Translations>` | —        | Translated strings. Omit for English                                      |
| `locale`       | `string`                | —        | BCP 47 locale for sizes and counts, such as `"fa"`. Omit for Latin digits |
| `children`     | `ReactNode`             | required | Your app                                                                  |

## Frequently asked questions

<Accordions>

<Accordion title="Where do file constraints come from?">

From the server. `useUpload` loads the route catalog (`GET /routes`) before
it presigns, and checks each file against the route's `fileTypes` and
`maxFileSize`. `accept` and `maxFileSize` on the hook can only narrow them.

</Accordion>

<Accordion title="How do I send auth tokens or cookies?">

Pass `headers` (a value or an async function) or `credentials: "include"` to
`createS3Client`, as in [step 1](#1-create-the-client).

</Accordion>

</Accordions>
