## Install

```npm

```

### API client [step]

Hooks use an `S3Api` client. Prefer `createS3Client` — one call gives you the
client, a bound provider, and a typed `useApi`.

<Tabs items={["@dimah-s3/server", "Custom backend"]}>

<Tab value="@dimah-s3/server">

If your backend uses [`@dimah-s3/server`](/docs/server/setup) on `/api/s3`:

```ts title="components/s3-provider.tsx"
"use client";

import { createS3Client } from "@dimah-s3/react";

export const { api, S3Provider, useApi } = createS3Client();

export function S3ClientProvider({ children }: { children: React.ReactNode }) {
  return <S3Provider>{children}</S3Provider>;
}
```

Custom base path / plugins / auth headers:

```ts
import { createS3Client } from "@dimah-s3/react";
import { dbClient } from "@dimah-s3/db/client";

export const { api, S3Provider, useApi } = createS3Client({
  basePath: "/api/your-path",
  plugins: [dbClient()],
  // cookies (same-origin) or Authorization via headers factory
  credentials: "include",
  headers: async () => ({
    Authorization: `Bearer ${await getAccessToken()}`,
  }),
});
```

Failed API calls throw `DimahS3Error` from `@dimah-s3/core` (with `.status`). Upload engine failures throw `S3UploadError` (extends it — `.code`, `.status`, `.phase`).

Use `api` directly (like Better Auth's client) or `useApi()` inside React.

</Tab>

<Tab value="Custom backend">

Implement the same `S3Api` contract with `defineApi`, then pass it to `S3Provider`:

```ts title="lib/s3-api.ts"
import { defineApi, S3Provider } from "@dimah-s3/react";

export const api = defineApi({
  async upload(payload) {
    const res = await fetch("/your-api/presign-upload", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify(payload),
    });
    if (!res.ok) {
      const body = await res.json().catch(() => ({}));
      throw new Error(body.message ?? res.statusText);
    }
    return res.json();
  },

  async confirm(payload) {
    /* your confirm endpoint */
  },
  async download(key, options) {
    /* your download endpoint */
  },
  async delete(key, options) {
    /* your delete endpoint */
  },
  multipart: {/* init, signPart, listParts, complete, abort */},
});

export function S3ClientProvider({ children }: { children: React.ReactNode }) {
  return <S3Provider api={api}>{children}</S3Provider>;
}
```

Payload and response types: [Custom backend](/docs/react/custom-backend).

### Provider [step]

Mount the provider once near your app root.

import { S3ClientProvider } from "@/components/s3-provider";

export default function RootLayout({
  children,

### First hook [step]

```tsx title="app/uploader.tsx"
"use client";

import { useUploadControls } from "@dimah-s3/react";

export function Uploader() {
  const { open, getInputProps, progress, isUploading } = useUploadControls({
    objectKey: (file) => `uploads/${Date.now()}-${file.name}`,
    accept: ["image/*", ".pdf"],
    maxFileSize: 10 * 1024 * 1024,
    noDrag: true,
    noClick: true,
    noKeyboard: true,
    onSuccess: (_file, result) => console.log(result.key),
  });

  return (
    <div>
      <input {...getInputProps()} />
      <button type="button" onClick={open} disabled={isUploading}>
        {isUploading ? `Uploading ${progress.percent}%` : "Upload file"}
      </button>
    </div>
  );
}
```

### Upload-only server config (recommended start) [step]

If your first screen only needs upload, keep other operations off:

```ts title="lib/s3.ts"
import { dimahS3 } from "@dimah-s3/server";
import { s3Client, defaultBucket } from "@/lib/s3-client";

export const s3 = dimahS3({
  s3: s3Client,
  defaultBucket,
  upload: { enabled: true },
  download: { enabled: false },
  delete: { enabled: false },
  multipart: { enabled: false },
});
```

Enable other features later when you need them.

### Resumable uploads (upload store) [step]

For multipart resume across refreshes, add an upload store:

```ts title="lib/upload-store.ts"
import { createLocalStorageStore } from "@dimah-s3/react";

export const localStorageStore = createLocalStorageStore();
```

```tsx title="app/uploader.tsx"
import { useUploadControls } from "@dimah-s3/react";
import { localStorageStore } from "@/lib/upload-store";

const { open, getInputProps } = useUploadControls({
  objectKey: (file) => `uploads/${Date.now()}-${file.name}`,
  multipart: true,
  uploadStore: localStorageStore,
  noDrag: true,
  noClick: true,
  noKeyboard: true,
});
```

Full guide: [Upload store](/docs/react/upload-store).
