`FileAttachment` shows a file row (name, size, preview, progress).
`StatusAttachment` is a lighter row for generic feedback like “Preparing…” or
errors. Both use the same shadcn Attachment sizes and orientations.

upload, download, and delete items — no separate registry package.

## On buttons and dropzones

Wired components render these rows for you. Pass `attachmentSize` /
`attachmentOrientation` so they stay separate from Button `size`:

```tsx
<UploadButton
  objectKey={(f) => `uploads/${f.name}`}
  size="sm"
  attachmentSize="xs"
/>
```

If you render status yourself, pass `size` and `orientation` on `UploadStatus`,
`MultiUploadStatus`, or `FileAttachment`.
