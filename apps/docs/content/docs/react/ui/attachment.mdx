package — file progress with preview, or lightweight operation feedback.

## Usage

```tsx
<FileAttachment
  state="uploading"
  fileName="report.pdf"
  fileSize={2_400_000}
  percent={64}
  onCancel={() => {}}
/>

<StatusAttachment state="processing" title="Preparing…" />
```

Wired controls (`UploadButton`, `UploadDropzone`, …) render these rows for you.
Pass `attachmentSize` / `attachmentOrientation` so layout stays separate from
Button `size`:

```tsx
<UploadButton
  objectKey={(f) => `uploads/${f.name}`}
  size="sm"
  attachmentSize="xs"
/>
```
