## Layout

Shared by both components (and by wired button/dropzone status via aliases):

<TypeTable
  type={{
    size: {
      description: "Attachment density. Defaults to sm.",
      type: '"default" | "sm" | "xs"',
      default: '"sm"',
    },
    orientation: {
      description: "Row layout. Vertical stacks media above the title.",
      type: '"horizontal" | "vertical"',
      default: '"horizontal"',
    },
    state: {
      description: "Visual state from the shadcn Attachment primitive.",
      type: '"idle" | "uploading" | "processing" | "error" | "done"',
      required: true,
    },
  }}
/>

On wired controls, use aliases so they stay separate from Button `size`:

| Attachment prop | On buttons / dropzone   |
| --------------- | ----------------------- |
| `size`          | `attachmentSize`        |
| `orientation`   | `attachmentOrientation` |

```tsx
<UploadButton
  objectKey={(f) => `uploads/${f.name}`}
  size="sm"
  attachmentSize="xs"
  attachmentOrientation="horizontal"
/>
```

<Callout type="info">
  If you render status yourself, pass `size` and `orientation` on
  `UploadStatus`, `MultiUploadStatus`, or the Attachment components directly.
</Callout>

## Install

Included with `@dimah-s3/ui`. Registry installs already ship these files with
upload, download, and delete items — no separate registry package.
