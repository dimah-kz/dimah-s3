Status UI is built on stock shadcn **Attachment**. Dimah wraps it as
`FileAttachment` (file name, size, preview, progress) and `StatusAttachment`
(operation feedback).

### Sizes

`size` mirrors Attachment: `default` | `sm` | `xs` (product default is `sm`).

`orientation` is `horizontal` (default) or `vertical`.

## Install

Shipped with `@dimah-s3/ui`. Registry installs include these files with upload,
download, and delete items — there is no separate registry package.

## Wired components

Buttons and dropzones already render these rows. Pass layout without clashing
with Button `size`:

| Prop                    | Maps to Attachment |
| ----------------------- | ------------------ |
| `attachmentSize`        | `size`             |
| `attachmentOrientation` | `orientation`      |

```tsx
<UploadButton objectKey={(f) => `uploads/${f.name}`} attachmentSize="xs" />
```

`UploadStatus` / `MultiUploadStatus` take `size` and `orientation` directly.
