## Status

Same [`Attachment`](/docs/react/ui/attachment) rows as `UploadButton`, including
`attachmentSize` / `attachmentOrientation` and the `status` prop
(`true` | `false` | render function).

`children` replaces only the idle chrome (icon + hints). To own the entire
interior, set `status={false}` and render `UploadStatus` yourself.

```tsx
<UploadDropzone
  objectKey={(f) => `uploads/${f.name}`}
  attachmentSize="xs"
  status={(node) => (
    <div className="w-full border-t border-dashed p-3">{node}</div>
  )}
>
  <div className="flex flex-1 items-center justify-center p-8">
    Drop files here
  </div>
</UploadDropzone>
```

## Headless alternative

Use [`useUpload`](/docs/react/hooks/upload#useupload) or [`useMultiUpload`](/docs/react/hooks/upload#usemultiupload) when you need full control over the UI.
