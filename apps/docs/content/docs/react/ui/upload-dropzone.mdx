Set `maxFiles` above `1` for multi-file uploads. The dropzone shows file limits, max size, and accepted types below the main label.

Status rows support [`attachmentSize` / `attachmentOrientation`](/docs/react/ui/attachment)
— the same aliases as `UploadButton`.

## Custom chrome and status

`children` replaces only the idle chrome (icon + hints). Status still follows the
`status` prop (`true` | `false` | render function). To own the entire interior,
set `status={false}` and render `UploadStatus` yourself.

Image uploads show a thumbnail in the status row (progress overlay while
uploading, full preview when done). Other file types keep the icon progress
row.

```tsx
<UploadDropzone
  objectKey={(f) => `uploads/${f.name}`}
  status={(node) => (
    <div className="w-full border-t border-dashed p-3">{node}</div>
  )}
>
  <div className="flex flex-1 items-center justify-center p-8">
    Drop files here
  </div>
</UploadDropzone>
```

## Headless alternative

Use [`useUpload`](/docs/react/hooks/upload#useupload) or [`useMultiUpload`](/docs/react/hooks/upload#usemultiupload) when you need full control over the UI.
