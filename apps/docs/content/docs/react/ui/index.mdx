[`@dimah-s3/ui`](https://www.npmjs.com/package/@dimah-s3/ui) provides accessible, theme-ready UI controls built on top of [shadcn](https://ui.shadcn.com) design tokens and `@dimah-s3/react` hooks.

## 1. Installation

<Tabs items={["npm package", "shadcn registry"]}>

<Tab value="npm package">

`@dimah-s3/core`, `@dimah-s3/react`, and `@fuma-translate/react` are peer
dependencies. Install them with the package:

```npm
npm i @dimah-s3/ui @dimah-s3/core @dimah-s3/react @fuma-translate/react shadcn
```

</Tab>

<Tab value="shadcn registry">

<include>../../../_includes/ui/index.mdx#registry-config</include>

```npm
npx shadcn@latest add @dimah-s3/upload
```

The registry copies the component source into your project and installs the
packages it needs.

</Tab>

</Tabs>

## 3. Mount Toaster

Mount one `<Toaster />` next to `<S3Provider>` in your root layout:

```tsx title="app/layout.tsx"
import { Toaster } from "@dimah-s3/ui"; // [!code ++]
import { S3Provider } from "@/lib/s3-client";

export default function RootLayout({
  children,
}: {
  children: React.ReactNode;
}) {
  return (
    <html lang="en">
      <body>
        <S3Provider>{children}</S3Provider>
        {/* [!code ++] */}
        <Toaster />
      </body>
    </html>
  );
}
```

## 4. Render a component

Each family has a root that holds one hook, and parts that read it. Toasts
are separate: mount `UploadToasts`, `DownloadToasts`, or `DeleteToasts` once
per hook.

```tsx title="components/avatar-uploader.tsx"
"use client";

import { useUpload } from "@dimah-s3/react";
import {
  Upload,
  UploadToasts,
  UploadTrigger,
  UploadStatus,
} from "@dimah-s3/ui";

export function AvatarUploader() {
  const upload = useUpload({ route: "avatar" });

  return (
    <>
      <Upload upload={upload}>
        <UploadTrigger />
        <UploadStatus />
      </Upload>
      <UploadToasts upload={upload} />
    </>
  );
}
```

Components never toast on their own. A second toast owner for the same hook
renders nothing and warns in development.

## Frequently asked questions

<Accordions>

<Accordion title="Can I use the components without installing the @dimah-s3/ui package?">

Yes. Add items from the shadcn registry to copy their source into your
codebase. The items are `upload`, `upload-field`, `avatar-upload`,
`object-image`, `download`, `delete`, `object-list`, and `file-attachment`:

```npm
npx shadcn@latest add @dimah-s3/upload @dimah-s3/delete
```

</Accordion>

<Accordion title="How do I translate the components?">

The components read their strings through `@fuma-translate/react`. See
[Internationalization](/docs/i18n).

</Accordion>

</Accordions>
