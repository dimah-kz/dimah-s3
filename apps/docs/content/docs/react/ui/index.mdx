You need a working [`S3Provider`](/docs/react/setup) first. After this page,
each [component](/docs/react/ui/components/upload-button) is an import or a
`shadcn add`.

## Install

<Tabs items={["npm package", "shadcn registry"]}>

<Tab value="npm package">

```npm
npm i @dimah-s3/ui shadcn
```

Import components from `@dimah-s3/ui`. The stylesheet and toaster come from the
same package.

</Tab>

<Tab value="shadcn registry">

<include>../../../_includes/ui/index.mdx#registry-config</include>

Then add items as you need them:

```npm
npx shadcn@latest add @dimah-s3/upload-button
```

Source lands in your app (usually under `components/dimah-s3/`). Toast UI comes
from shadcn [toast](https://ui.shadcn.com/docs/components/base/toast).

</Tab>

</Tabs>

## Styles

Import the UI stylesheet so Tailwind can scan package classes. It also maps
`--color-dimah-s3-*` to your [shadcn theme](https://ui.shadcn.com/docs/theming)
by default — see [Theming](/docs/react/ui/customization/theming).

<include>../../../_includes/ui/index.mdx#styles</include>

Keep the usual shadcn variables (`--primary`, `--muted`, …) in the same file.

`shadcn add` injects the
[color bridge](/docs/react/ui/customization/theming#registry-only) so
`*-dimah-s3-*` utilities resolve. Registry-only apps that skipped that CSS
update can paste it from the theming page.

## Toaster

Mount a toaster once, next to your provider. The wired upload, download, and
delete controls use it for status toasts.

<Tabs items={["npm package", "shadcn registry"]}>

<Tab value="npm package">

```tsx title="app/layout.tsx"
import { Toaster } from "@dimah-s3/ui";

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body>
        {children}
        <Toaster />
      </body>
    </html>
  );
}
```

If you already mount shadcn toast for your own messages, keep both. Alias one
import (`Toaster as DimahToaster`) so they do not collide. App toasts stay on
`import { toast } from "@/components/ui/toast"`.

</Tab>

<Tab value="shadcn registry">

```tsx title="app/layout.tsx"
import { Toaster } from "@/components/ui/toast";

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body>
        {children}
        <Toaster />
      </body>
    </html>
  );
}
```

Use `toast.add`, `toast.update`, `toast.close`, and `toast.promise` from that
module. The older Sonner helpers (`toast.success`, `toast.error`, …) are not
available on this toaster.

</Tab>

</Tabs>
