## Usage

```tsx
<UploadButton
  objectKey={(f) => `uploads/${f.name}`}
  maxFiles={5}
  variant="secondary"
  size="sm"
  attachmentSize="xs"
/>
```

Inline status uses [`Attachment`](/docs/react/ui/attachment) rows. Control it with
`status`:

| Value                 | Behavior                    |
| --------------------- | --------------------------- |
| `true` (default)      | Render below the button     |
| `false`               | Hide status                 |
| `(node) => ReactNode` | Wrap or relocate the status |

`attachmentSize` / `attachmentOrientation` set row density without changing
Button `size`. Toasts are independent via `toast`.

<Callout type="warn">
  `accept` and `maxFileSize` are enforced **client-side only**. Mirror the same
  limits in `upload.presignGuard` on the server.
</Callout>
