## Button appearance

`UploadButton`, `DownloadButton`, `ProgressDownloadButton`, and `DeleteButton` share optional shadcn button props:

| Prop              | Description                                         |
| ----------------- | --------------------------------------------------- |
| `variant`         | shadcn button variant (defaults vary per component) |
| `size`            | shadcn button size (`default` if omitted)           |
| `buttonClassName` | Extra classes on the trigger button                 |

```tsx
<UploadButton variant="secondary" size="sm" objectKey="uploads/file" />
<DownloadButton variant="ghost" objectKey="uploads/report.pdf" />
<DeleteButton variant="outline" objectKey="uploads/report.pdf" />
```

## Status

Inline status uses [`FileAttachment` / `StatusAttachment`](/docs/react/ui/attachment).
Control placement with `status`:

| Value                    | Behavior                         |
| ------------------------ | -------------------------------- |
| `true` (default)         | Render below the button          |
| `false`                  | Hide status                      |
| `(node) => ReactNode`    | Wrap or relocate the status node |

Tune density with `attachmentSize` / `attachmentOrientation` (separate from Button `size`):

```tsx
<UploadButton
  objectKey={(f) => `uploads/${f.name}`}
  size="sm"
  attachmentSize="xs"
  status={(node) => <aside className="ms-auto w-72">{node}</aside>}
/>
```

Image uploads show a thumbnail (progress overlay while uploading). Other types
keep the file-type icon. Toasts stay independent via `toast`.

## Composition

Prefer the wired button for the happy path. For a fully custom layout, combine
[`useUpload`](/docs/react/hooks/upload#useupload) with
`UploadStatus` (or the exported `Attachment` primitives):

```tsx
import { useUpload } from "@dimah-s3/react";
import { UploadStatus } from "@dimah-s3/ui";

function CustomUpload() {
  const ctrl = useUpload({
    objectKey: (f) => `uploads/${f.name}`,
  });

  return (
    <>
      <button type="button" onClick={ctrl.open}>
        Choose file
      </button>
      <UploadStatus
        phase={ctrl.phase}
        progress={ctrl.progress}
        error={ctrl.error}
        fileInfo={ctrl.fileInfo}
        onCancel={ctrl.cancel}
        size="xs"
      />
    </>
  );
}
```
