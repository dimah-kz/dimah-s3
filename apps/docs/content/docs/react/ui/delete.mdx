## Usage

```tsx
<DeleteButton
  objectKey="uploads/report.pdf"
  onSuccess={() => {
    /* sync your database */
  }}
/>
```

Inline status uses [`StatusAttachment`](/docs/react/ui/attachment)
(`attachmentSize` / `attachmentOrientation`).

<Callout type="tip">
  Wire `onSuccess` to a database mutation so app records stay in sync after
  deletion.
</Callout>
