`ObjectCard` shows a file you already stored, such as an attachment on a
record, with a download and a delete action. Pass the object key and the
hooks for the actions you want. While its file downloads it shows the
progress, and while it is deleted, a spinner.

## Usage

```tsx
"use client";

import { useDelete, useFetchDownload } from "@dimah-s3/react";
import { DeleteToasts, DownloadToasts, ObjectCard } from "@dimah-s3/ui";

type Attachment = { key: string; size: number; type: string };

export function Attachments({
  files,
  onRemoved,
}: {
  files: Attachment[];
  onRemoved: (key: string) => void;
}) {
  const download = useFetchDownload({ route: "attachments" });
  const remove = useDelete({ route: "attachments" });

  return (
    <>
      {files.map((file) => (
        <ObjectCard
          key={file.key}
          objectKey={file.key}
          fileSize={file.size}
          contentType={file.type}
          download={download}
          delete={remove}
          onDeleted={(result) => {
            if (result.deleted.includes(file.key)) onRemoved(file.key);
          }}
        />
      ))}
      <DownloadToasts download={download} />
      <DeleteToasts delete={remove} />
    </>
  );
}
```

- The name defaults to the last segment of the key. Pass `fileName` to
  show, and save, another one.
- `download` takes `useDownload` or `useFetchDownload`. With a fetch
  download the card shows its progress ring and the bytes received.
- `delete` adds the delete action and its confirm dialog. The card stays
  until you remove it, so drop it in `onDeleted`.
- Pass `previewUrl` for an image thumbnail, and `description` to replace
  the size line.
- Each card is its own `Download` and `Delete` root, and does not toast:
  mount `DownloadToasts` and `DeleteToasts` once for the hooks.
