## Usage

```tsx
"use client";

import { useDownload } from "@dimah-s3/react";
import { ProgressDownloadButton } from "@dimah-s3/ui";

export function DocumentDownloader({ documentKey }: { documentKey: string }) {
  const download = useDownload({ route: "document", mode: "fetch" });

  return <ProgressDownloadButton download={download} objectKey={documentKey} />;
}
```

## Frequently asked questions

<Accordions>

<Accordion title="How do I dismiss the status row after a download?">

Use the dismiss control on a completed or failed attachment, or call
`download.reset()` yourself.

</Accordion>

<Accordion title="How does cancellation work?">

Click the button while a download is active to abort the underlying fetch
stream and reset the button state.

</Accordion>

<Accordion title="Does this work with private buckets?">

Yes. The download request passes through the server route guards and obtains a
signed URL before the fetch stream starts; the bucket does not need to be
public.

</Accordion>

</Accordions>
