Built on [`useUpload`](/docs/react/hooks/upload) /
[`useMultiUpload`](/docs/react/hooks/upload#usemultiupload) and a shadcn
[Button](https://ui.shadcn.com/docs/components/base/button). Progress and
errors use [`Attachment`](/docs/react/ui/components/attachment) rows.

## Usage

```tsx
<UploadButton
  objectKey={(f) => `uploads/${f.name}`}
  maxFiles={5}
  variant="secondary"
  size="sm"
  attachmentSize="xs"
/>
```

Control the status row with `status`:

| Value                 | Behavior                    |
| --------------------- | --------------------------- |
| `true` (default)      | Render below the button     |
| `false`               | Hide status                 |
| `(node) => ReactNode` | Wrap or relocate the status |

Toasts are independent via the `toast` prop. For a custom trigger that still
uses Attachment rows, see
[Custom UI](/docs/react/ui/customization/custom-ui).

<Callout type="warn">
  `accept` and `maxFileSize` are enforced **client-side only**. Mirror the same
  limits in `upload.presignGuard` on the server.
</Callout>
