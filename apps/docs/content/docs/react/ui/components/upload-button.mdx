`UploadButton` opens the native file picker. Create the uploader with
[`useUpload`](/docs/react/hooks/upload) and pass it as `upload`.

## Usage

```tsx
"use client";

import { useUpload } from "@dimah-s3/react";
import { UploadButton } from "@dimah-s3/ui";

export function Uploader() {
  const upload = useUpload({
    route: "uploads",
    maxFiles: 5,
  });

  return <UploadButton upload={upload} />;
}
```

Control the status row with `status`:

| Value                 | Behavior                    |
| --------------------- | --------------------------- |
| `true` (default)      | Render below the button     |
| `false`               | Hide status                 |
| `(node) => ReactNode` | Wrap or relocate the status |

Toasts are independent via the `toast` prop. Relocate status with
[`UploadStatus`](/docs/react/ui/components/upload-dropzone) (`upload` is
the same instance) or build your own rows — see
[Custom UI](/docs/react/ui/customization/custom-ui).

<Callout type="warn">
  Omit `accept` / `maxFileSize` so the hook fills them from
  [`api.catalog()`](/docs/server/routes). The server still enforces
  `upload.fileTypes` / `upload.maxFileSize`. Explicit hook values override the
  catalog for client UX only.
</Callout>
