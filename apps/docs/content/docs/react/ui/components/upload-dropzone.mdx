`UploadDropzone` is a drag-and-drop upload surface powered by
[`useUpload`](/docs/react/hooks/upload) /
[`useMultiUpload`](/docs/react/hooks/upload#usemultiupload). Upload options
match [Upload Button](/docs/react/ui/components/upload-button); set `maxFiles`
above `1` for multi-file uploads.

Progress and errors use the same
[`Attachment`](/docs/react/ui/components/attachment) rows as the button.
`children` replace the idle chrome only. The `status` prop accepts `true`,
`false`, or a render function — same contract as `UploadButton`.

## Usage

```tsx
<UploadDropzone
  objectKey={(f) => `uploads/${f.name}`}
  maxFiles={5}
  attachmentSize="xs"
  status={(node) => (
    <div className="w-full border-t border-dashed p-3">{node}</div>
  )}
>
  <div className="flex flex-1 items-center justify-center p-8">
    Drop files here
  </div>
</UploadDropzone>
```

To own the entire interior, set `status={false}` and render `UploadStatus`
yourself — see [Custom UI](/docs/react/ui/customization/custom-ui).

<Callout type="warn">
  `accept` and `maxFileSize` are enforced **client-side only**. Mirror the same
  limits in `upload.presignGuard` on the server.
</Callout>
