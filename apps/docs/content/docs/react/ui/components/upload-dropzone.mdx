[Upload Button](/docs/react/ui/components/upload-button).

## Usage

Set `maxFiles` above `1` for multi-file uploads. `children` replace the idle
chrome only; `status` works like `UploadButton`.

```tsx
<UploadDropzone
  objectKey={(f) => `uploads/${f.name}`}
  maxFiles={5}
  attachmentSize="xs"
  status={(node) => (
    <div className="w-full border-t border-dashed p-3">{node}</div>
  )}
>
  <div className="flex flex-1 items-center justify-center p-8">
    Drop files here
  </div>
</UploadDropzone>
```

To own the entire interior, set `status={false}` and render `UploadStatus`
yourself — see [Custom UI](/docs/react/ui/customization/custom-ui).

<Callout type="warn">
  `accept` and `maxFileSize` are enforced **client-side only**. Mirror the same
  limits in `upload.presignGuard` on the server.
</Callout>
