`UploadDropzone` is a drag-and-drop surface. Create the uploader with
[`useUpload`](/docs/react/hooks/upload) and pass it as `upload`.

## Preview

<DemoPreview name="upload-dropzone-demo.tsx">
  <UploadDropzoneDemo />
</DemoPreview>

Progress and errors use [`Attachment`](/docs/react/ui/components/attachment)
rows.

Intake is [react-dropzone](https://react-dropzone.js.org/). Do not install
it separately — `@dimah-s3/react` already includes it.

## Usage

Set `maxFiles` above `1` on the hook for multi-file uploads. `children`
replace the idle chrome only; `status` works like `UploadButton`.

```tsx
"use client";

import { useUpload } from "@dimah-s3/react";
import { UploadDropzone, UploadStatus } from "@dimah-s3/ui";

export function Uploader() {
  const upload = useUpload({
    route: "uploads",
    maxFiles: 5,
  });

  return (
    <>
      <UploadDropzone upload={upload} attachmentSize="xs" status={false}>
        <div className="flex flex-1 items-center justify-center p-8">
          Drop files here
        </div>
      </UploadDropzone>
      <UploadStatus upload={upload} attachmentSize="xs" />
    </>
  );
}
```

To own the entire interior, set `status={false}` and render `UploadStatus`
yourself — see [Custom UI](/docs/react/ui/customization/custom-ui).

<Callout type="warn">
  `accept` and `maxFileSize` are enforced **client-side only**. Mirror the same
  limits in `upload.fileTypes` / `upload.maxFileSize` on the server route, or
  omit them on the hook so [`api.catalog()`](/docs/server/routes) fills them.
</Callout>
