`UploadDropzone` is a drop target with the same upload options as
[`UploadButton`](/docs/react/ui/components/upload-button). Set `maxFiles` above `1` for
multi-file uploads.

## Usage

```tsx
<UploadDropzone
  objectKey={(f) => `uploads/${f.name}`}
  maxFiles={5}
  attachmentSize="xs"
  status={(node) => (
    <div className="w-full border-t border-dashed p-3">{node}</div>
  )}
>
  <div className="flex flex-1 items-center justify-center p-8">
    Drop files here
  </div>
</UploadDropzone>
```

`children` replaces the idle chrome only. Status follows the same `status` prop
as `UploadButton` (`true` | `false` | render function). To own the entire
interior, set `status={false}` and render `UploadStatus` yourself.

<Callout type="warn">
  `accept` and `maxFileSize` are enforced **client-side only**. Mirror the same
  limits in `upload.presignGuard` on the server.
</Callout>
