import { DeleteButtonDemo } from "@/components/demos/delete-button-demo";

`DeleteButton` runs the two-step [`useDelete`](/docs/react/hooks/delete) flow
behind a shadcn [Button](https://ui.shadcn.com/docs/components/base/button) and
[Alert Dialog](https://ui.shadcn.com/docs/components/base/alert-dialog).

After confirm, status feedback uses
[`StatusAttachment`](/docs/react/ui/components/attachment)
(`attachmentSize` / `attachmentOrientation`). Wire `onSuccess` to a database
mutation so app records stay in sync after the object is removed.

## Usage

```tsx
<DeleteButton
  objectKey="uploads/report.pdf"
  onSuccess={() => {
    /* sync your database */
  }}
/>
```
