`DeleteButton` removes an S3 object after a confirmation dialog, with inline
status.

## Preview

<DemoPreview name="delete-button-demo.tsx">
  <DeleteButtonDemo />
</DemoPreview>

Built on [`useDelete`](/docs/react/hooks/delete), a shadcn
[Button](https://ui.shadcn.com/docs/components/base/button), and
[Alert Dialog](https://ui.shadcn.com/docs/components/base/alert-dialog). Status
uses [`StatusAttachment`](/docs/react/ui/components/attachment). Wire
`onSuccess` to keep your database in sync.

## Usage

```tsx
<DeleteButton
  route="uploads"
  objectKey={storedKey}
  onSuccess={() => {
    /* sync your database */
  }}
/>
```

`objectKey` is the stored S3 key (`result.key` from upload). The prop is not
named `key` because React reserves that for lists.
