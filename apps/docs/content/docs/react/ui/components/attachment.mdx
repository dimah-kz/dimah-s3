`FileAttachment` and `StatusAttachment` are shared status rows built on shadcn
[`Attachment`](https://ui.shadcn.com/docs/components/base/attachment).

## Preview

<AttachmentPlaygroundPreview />

[Upload Button](/docs/react/ui/components/upload-button) and
[Upload Dropzone](/docs/react/ui/components/upload-dropzone) use them for
inline progress and file info.
[Download Button](/docs/react/ui/components/download-button),
[Progress Download Button](/docs/react/ui/components/progress-download-button),
and [Delete Button](/docs/react/ui/components/delete-button) use
`StatusAttachment` for error and status feedback.

You can also render these rows yourself next to a headless hook — see
[Custom UI](/docs/react/ui/customization/custom-ui).

| Component          | Use when                                                       |
| ------------------ | -------------------------------------------------------------- |
| `FileAttachment`   | File name, size, preview, and upload progress                  |
| `StatusAttachment` | Generic status — preparing, deleting, or a plain error message |

## Usage

```tsx
<FileAttachment
  state="uploading"
  fileName="quarterly-report.pdf"
  fileSize={2_400_000}
  percent={64}
  onCancel={() => {}}
/>

<FileAttachment
  state="uploading"
  fileName="avatar.png"
  fileType="image/png"
  fileSize={180_000}
  previewUrl="/dimah-avatar.jpg"
  percent={42}
/>

<StatusAttachment state="processing" title="Preparing…" />
```

Wired controls expose `attachmentSize` / `attachmentOrientation` so row density
stays independent of Button `size`.

For a hook-driven row that maps upload phase automatically, use `UploadStatus`
(or `MultiUploadStatus`) as shown in [Custom UI](/docs/react/ui/customization/custom-ui).
