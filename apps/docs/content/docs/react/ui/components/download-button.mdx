import { DownloadButtonDemo } from "@/components/demos/download-button-demo";

`DownloadButton` requests a presigned URL and starts a browser download. No
progress UI — use [`Progress Download Button`](/docs/react/ui/components/progress-download-button)
when you need a live progress fill.

## Usage

```tsx
<DownloadButton objectKey="uploads/report.pdf" variant="ghost" />
```

Errors render as a [`StatusAttachment`](/docs/react/ui/components/attachment) row
(`attachmentSize` / `attachmentOrientation`).
