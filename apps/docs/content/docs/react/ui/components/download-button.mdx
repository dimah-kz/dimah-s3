import { DownloadButtonDemo } from "@/components/demos/download-button-demo";

`DownloadButton` requests a presigned URL and starts a native browser download.

## Preview

<DemoPreview name="download-button-demo.tsx">
  <DownloadButtonDemo />
</DemoPreview>

Built on [`useDownload`](/docs/react/hooks/download) and a shadcn
[Button](https://ui.shadcn.com/docs/components/base/button). No progress fill —
only a spinner while presigning. On failure, a
[`StatusAttachment`](/docs/react/ui/components/attachment) row appears below.

## Install

One-time styles and toaster: [Setup](/docs/react/ui/setup).

<Tabs items={["npm package", "shadcn registry"]}>

<Tab value="npm package">

```tsx
import { DownloadButton } from "@dimah-s3/ui";
```

</Tab>

<Tab value="shadcn registry">

```npm
npx shadcn@latest add @dimah-s3/download-button
```

</Tab>

</Tabs>

## Usage

```tsx
<DownloadButton objectKey="uploads/report.pdf" variant="ghost" />
```
