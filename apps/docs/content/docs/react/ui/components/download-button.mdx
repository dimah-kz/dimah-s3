`DownloadButton` requests a presigned URL and starts a native browser
download. Create the downloader with
[`useDownload`](/docs/react/hooks/download) and pass it as `download`.

## Preview

Built on a shadcn
[Button](https://ui.shadcn.com/docs/components/base/button). There is no
progress fill — only a spinner while the URL is signed. On failure, a
[`StatusAttachment`](/docs/react/ui/components/attachment) row appears below.

## Usage

```tsx
"use client";

import { useDownload } from "@dimah-s3/react";
import { DownloadButton } from "@dimah-s3/ui";

export function SaveFile({ storedKey }: { storedKey: string }) {
  const download = useDownload({ route: "uploads" });

  return (
    <DownloadButton download={download} objectKey={storedKey} variant="ghost" />
  );
}
```

`objectKey` is the stored S3 key (`result.key` from upload). The hook
`route` must have `download` enabled — the same route as upload when those
keys were created there. The prop is not named `key` because React reserves
that for lists.

Pass a navigate-mode return (`useDownload()` without `mode: "fetch"`). For
progress and cancel, use
[Progress Download Button](/docs/react/ui/components/progress-download-button).

A list can share one `useDownload` — the hook tracks `objectKey`, so spinner,
status, and toasts only apply to the matching control. Call the hook inside
the row when downloads must run in parallel.
