The wired controls are a starting point. Build your own UI on
`@dimah-s3/react` hooks, install a registry item and edit the source in your
app, or use both as a reference.

This example pairs [`useUpload`](/docs/react/hooks/upload) with shadcn
[`Attachment`](https://ui.shadcn.com/docs/components/base/attachment) from
your app. Map `phase` onto `state`, and hide the row while `phase` is `idle`.

If you have not already, complete [UI setup](/docs/react/ui)
(stylesheet and toaster).

## When to use what

| Goal                               | Use                                                                                                              |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| Finished control                   | [Upload Button](/docs/react/ui/components/upload-button) / [Dropzone](/docs/react/ui/components/upload-dropzone) |
| Install and customize              | Registry item, then edit the generated source                                                                    |
| Custom trigger + shadcn chrome     | Hook + your own shadcn components (this page)                                                                    |
| Custom trigger + dimah status rows | Hook + [`FileAttachment`](/docs/react/ui/components/attachment) / `UploadStatus`                                 |
| Fully custom chrome                | Hook only — [Upload hooks](/docs/react/hooks/upload)                                                             |

Same pattern for download and delete:
[`useDownload`](/docs/react/hooks/download) /
[`useDelete`](/docs/react/hooks/delete). Pass the return as `download` /
`delete`. The target key stays on the control as `objectKey`. A list can
share one hook — status and toasts follow the hook's `objectKey`. For
multiple files, pass `maxFiles` on [`useUpload`](/docs/react/hooks/upload).

Stock toasts and status rows are also exported: `useUploadUi`,
`useDownloadUi`, `useDeleteUi`, plus the toast hooks if you only want
those.
