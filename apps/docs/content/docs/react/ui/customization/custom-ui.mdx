The wired controls are a starting point, not the only path. You can build your
own UI on top of `@dimah-s3/react` hooks, install items from the shadcn registry
and edit the source in your app, or use both as a reference.

This example pairs [`useUpload`](/docs/react/hooks/upload) with stock shadcn
[`Attachment`](https://ui.shadcn.com/docs/components/base/attachment) from your
app (`npx shadcn@latest add attachment`). Map `phase` onto `state`, and hide
the row while `phase` is `idle`.

One-time styles: [Setup](/docs/react/ui/setup).

## When to use what

| Goal                               | Use                                                                                                              |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| Finished control                   | [Upload Button](/docs/react/ui/components/upload-button) / [Dropzone](/docs/react/ui/components/upload-dropzone) |
| Install and customize              | `npx shadcn@latest add @dimah-s3/…` then edit the generated source                                               |
| Custom trigger + shadcn chrome     | Hook + your own shadcn components (this page)                                                                    |
| Custom trigger + dimah status rows | Hook + [`FileAttachment`](/docs/react/ui/components/attachment) / `UploadStatus`                                 |
| Fully custom chrome                | Hook only — [Upload hooks](/docs/react/hooks/upload)                                                             |

Same pattern for download and delete:
[`useDownload`](/docs/react/hooks/download) /
[`useDelete`](/docs/react/hooks/delete). For multiple files, use
[`useMultiUpload`](/docs/react/hooks/upload#usemultiupload).
