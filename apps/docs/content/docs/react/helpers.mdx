Import display helpers from `@dimah-s3/react`. File helpers live in
`@dimah-s3/core` — the upload hooks already call them for you.

## Progress

```ts
import { formatUploadProgress, formatSpeed, formatEta } from "@dimah-s3/react";

formatUploadProgress(1_200_000, 5_600_000, 21);
// "1.2 MB / 5.6 MB (21%)"

formatSpeed(1_200_000); // "1.2 MB/s"
formatEta(4_400_000, 450_000); // "9s"
```

`onProgress` from the hooks already includes `speed` when it is measurable.

## Accept labels

Short labels from HTML `accept` entries — no sentences, so you can localize
the copy. [Upload Dropzone](/docs/react/ui/components/upload-dropzone) uses
this for its hint.

```ts
import { formatAcceptLabels } from "@dimah-s3/react";

formatAcceptLabels(["image/*", ".pdf", ".txt"]);
// ["Images", "PDF", "TXT"]
```

## Validation and size

`validateFile` returns `null` or `{ code, message, params }`. Client checks
are not a security boundary — mirror them in
[`upload.fileTypes` / `upload.maxFileSize`](/docs/server/routes).

```ts
import { validateFile, formatFileSize, truncateFileName } from "@dimah-s3/core";

validateFile(file, { accept: ["image/*"], maxFileSize: 10 * 1024 * 1024 });
// null | { code: "FILE_TYPE_NOT_ALLOWED", message, params }

formatFileSize(1_500_000); // "1.4 MB"
truncateFileName("very-long-document-name.pdf"); // "very-long-documen… .pdf"
```

## Checksum, magic bytes, and public URLs

Checksum, magic-byte sniffing, and public object URLs also export from
`@dimah-s3/core` (and from `@dimah-s3/react`). Typed route names are
`S3RouteName` / `InferS3Routes`.

```ts
import {
  sha256File,
  sniffContentType,
  matchesMagicBytes,
  buildPublicObjectUrl,
} from "@dimah-s3/core";

await sha256File(file);
sniffContentType(new Uint8Array(await file.slice(0, 16).arrayBuffer()));
buildPublicObjectUrl({ baseUrl: "https://cdn.example.com", key });
```

Inside React, map the error with `useFormatValidateFileError()`:

```tsx
import { useFormatValidateFileError } from "@dimah-s3/react";
import { validateFile } from "@dimah-s3/core";

const format = useFormatValidateFileError();
const error = validateFile(file, { accept: ["image/*"] });
const message = error ? format(error) : null;
```

## File names

`createS3Client` already sanitizes `fileName` on download requests.

```ts
import {
  sanitizeFileName,
  parseFileName,
  fileNameFromKey,
} from "@dimah-s3/core";

sanitizeFileName('file"name.pdf'); // file_name.pdf
parseFileName(res.headers.get("content-disposition")); // "report.pdf" | undefined
fileNameFromKey("uploads/uuid/photo.jpg"); // "photo.jpg"
```

## API errors

Failed `S3Api` calls throw `APIError`. Format them for the UI with
`useFormatDimahError` (keys off `.code`). Catch with `isAPIError`:

```tsx
import { isAPIError, useFormatDimahError } from "@dimah-s3/react";

const formatError = useFormatDimahError();

try {
  await api.download({ route: "uploads", key });
} catch (err) {
  if (isAPIError(err)) toast.error(formatError(err));
}
```
