---
title: useUpload
description: Headless React hook for single and multi-file S3 uploads with progress and retries.
---

`useUpload` manages the entire client-side upload lifecycle: file selection, validation, presigned URL requests, progress tracking, and confirmation.

```tsx
"use client";

import { useUpload } from "@dimah-s3/react";

export function AvatarUploader() {
  const upload = useUpload({
    route: "avatar",
    onSuccess: (results) => {
      console.log("Uploaded key:", results[0]?.key);
    },
  });

  return (
    <div
      {...upload.getRootProps()}
      className="border p-4 rounded text-center cursor-pointer"
    >
      <input {...upload.getInputProps()} />
      {upload.isUploading
        ? `Uploading: ${upload.progress.percent}%`
        : "Drop an avatar image or click to choose"}
    </div>
  );
}
```

## Multi-file uploads

Set `maxFiles` to allow multiple file selections:

```tsx
"use client";

import { useUpload } from "@dimah-s3/react";
import { UploadDropzone } from "@dimah-s3/ui";

export function GalleryUploader() {
  const upload = useUpload({
    route: "gallery",
    maxFiles: 5,
    onSuccess: (results) => {
      const keys = results.map((r) => r.key);
      saveGalleryKeys(keys);
    },
  });

  return <UploadDropzone upload={upload} />;
}
```

## Uploading files programmatically

If you already have a `File` object (e.g. from canvas, paste, or custom inputs):

```tsx
const upload = useUpload({ route: "avatar" });

await upload.handleFiles(file); // accepts File, File[], or FileList
```

## Options reference

| Option          | Default | Description                                                                   |
| --------------- | ------- | ----------------------------------------------------------------------------- |
| `route`         | —       | Required. Named server route (`dimahS3({ routes })`)                          |
| `maxFiles`      | `1`     | Maximum number of files per upload batch                                      |
| `accept`        | Auto    | HTML accept filter (automatically populated from route catalog)               |
| `maxFileSize`   | Auto    | Maximum file size in bytes (automatically populated from route catalog)       |
| `onSuccess`     | —       | Callback when all files finish uploading: `(results: UploadResult[]) => void` |
| `onFileSuccess` | —       | Callback per file: `(file: File, result: UploadResult) => void`               |
| `onError`       | —       | Error callback with typed `APIError`                                          |
| `checksum`      | Auto    | Enable SHA-256 client hashing before upload                                   |
| `uploadStore`   | —       | Optional store to persist in-progress uploads across reloads                  |

## Frequently asked questions

<Accordion title="How do I display a local image preview before uploading?">

Use the `files` array from `upload` to generate object URLs for preview:

```tsx
export function AvatarWithPreview() {
  const upload = useUpload({ route: "avatar" });
  const activeFile = upload.files[0]?.file;
  const previewUrl = activeFile ? URL.createObjectURL(activeFile) : null;

  return (
    <div>
      <div {...upload.getRootProps()}>
        <input {...upload.getInputProps()} />
        {previewUrl ? (
          <img
            src={previewUrl}
            alt="Preview"
            className="size-20 rounded-full"
          />
        ) : (
          <button type="button">Select avatar</button>
        )}
      </div>
      {upload.isUploading && <span>{upload.progress.percent}%</span>}
    </div>
  );
}
```

</Accordion>

<Accordion title="How do I trigger the file picker from a custom button?">

Call `upload.open()` to open the native OS file picker programmatically:

```tsx
<button type="button" onClick={() => upload.open()}>
  Change Avatar
</button>
```

</Accordion>

<Accordion title="How do I pass custom metadata along with the upload?">

Use `uploadOptions` or `getUploadOptions`:

```tsx
const upload = useUpload({
  route: "avatar",
  uploadOptions: {
    metadata: { source: "web-profile" },
  },
});
```
