---
title: Upload
description: Upload hooks for single and multiple files.
---

| Hook                                       | Use case                          |
| ------------------------------------------ | --------------------------------- |
| `useUpload`                                | One file — picker + drag-and-drop |
| `useMultiUpload`                           | Many files — picker + drop        |
| `useFileUpload` / `useMultiFileUpload`     | You already have a `File`         |

<Callout>
  Enforce `accept` and `maxFileSize` on the server too (`presignGuard`).
</Callout>

---

## `useUpload`

Same pattern as [`UploadButton`](/docs/react/ui/upload-button) and [`UploadDropzone`](/docs/react/ui/upload-dropzone). Built on [react-dropzone](https://react-dropzone.js.org/) (`getRootProps` / `getInputProps`).

```tsx
"use client";

import { useUpload } from "@dimah-s3/react";

const {
  getRootProps,
  getInputProps,
  isDragActive,
  isDragAccept,
  isDragReject,
  fileRejections,
  phase,
  progress,
  isUploading,
  cancel,
} = useUpload({
  objectKey: (file) => `uploads/${Date.now()}-${file.name}`,
  accept: ["image/*"],
  maxFileSize: 10 * 1024 * 1024,
  onFileReject: (rejections) => console.warn(rejections),
  onSuccess: (file, result) => console.log(result.key),
});

return (
  <div
    {...getRootProps({
      className: isDragReject
        ? "border-red-500"
        : isDragAccept
          ? "border-green-500"
          : isDragActive
            ? "border-blue-500"
            : undefined,
    })}
  >
    <input {...getInputProps()} />
    {isUploading
      ? `${progress.percent}%`
      : isDragReject
        ? "File type or size not allowed"
        : isDragActive
          ? "Drop to upload"
          : "Click or drop to upload"}
    {fileRejections.length > 0 && (
      <p>{fileRejections[0]?.errors[0]?.message}</p>
    )}
  </div>
);
```

For a button-only UI (no drag), pass `noDrag`, `noClick`, and `noKeyboard`, then call `open()` from your button.

`UploadDropzone` already styles accept/reject drags and toasts soft rejections when `toast` is enabled.

## `useMultiUpload`

Same as above, for multiple files. Set `maxFiles`.

```tsx
"use client";

import { useMultiUpload } from "@dimah-s3/react";

const {
  getRootProps,
  getInputProps,
  files,
  totalProgress,
  isUploading,
  cancel,
} = useMultiUpload({
  objectKey: (file) => `uploads/${Date.now()}-${file.name}`,
  maxFiles: 5,
  concurrentFiles: 3,
  accept: ["image/*"],
  onSuccess: (results) => console.log(results.map((r) => r.key)),
});

return (
  <div {...getRootProps()}>
    <input {...getInputProps()} />
    {isUploading
      ? `${totalProgress.percent}% — ${files.filter((f) => f.status === "success").length}/${files.length}`
      : "Click or drop files"}
  </div>
);
```

<Callout type="info">
  `multipart` splits one large file into parts — it is not multi-file upload.
</Callout>

## Lower-level hooks

Skip the picker when you already have a `File`.

### `useFileUpload`

```tsx
const { phase, progress, upload, cancel, reset } = useFileUpload();

await upload(file, `uploads/${file.name}`, { metadata: { userId: "1" } });
```

### `useMultiFileUpload`

```tsx
const { files, totalProgress, upload, cancel, reset } = useMultiFileUpload({
  maxFiles: 10,
  concurrentFiles: 3,
});

await upload(fileArray, (file) => `uploads/${file.name}`);
```

Same engine options as the intake hooks (`accept`, `maxFileSize`, `onSuccess`, …).
