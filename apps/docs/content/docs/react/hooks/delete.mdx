---
title: Delete
description: Two-step delete with an optional confirm step.
---

`requestDelete` marks a key pending; `confirmDelete` sends the request — so you can show a dialog in between.

```tsx
"use client";

import { useDelete } from "@dimah-s3/react";

const { phase, pendingKey, requestDelete, confirmDelete, cancelDelete } =
  useDelete({
    onSuccess: (key) => console.log("Deleted:", key),
  });

requestDelete("uploads/photo.jpg");
await confirmDelete();
```

No dialog needed? Call both at once:

```ts
requestDelete(key);
await confirmDelete();
```
