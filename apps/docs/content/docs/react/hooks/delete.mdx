---
title: useDelete
description: Headless hook for single, batch, and confirmation-driven object deletion.
---

`useDelete` coordinates object deletion with optional two-step confirmation flows.

```tsx
"use client";

import { useDelete } from "@dimah-s3/react";

export function DeleteAvatar({ avatarKey }: { avatarKey: string }) {
  const {
    isConfirming,
    requestDelete,
    confirmDelete,
    cancelDelete,
    isDeleting,
  } = useDelete({
    route: "avatar",
    onSuccess: (key) => {
      console.log("Deleted key:", key);
    },
  });

  if (isConfirming) {
    return (
      <div className="flex items-center gap-2">
        <span>Are you sure?</span>
        <button onClick={() => void confirmDelete()} disabled={isDeleting}>
          Confirm
        </button>
        <button onClick={cancelDelete}>Cancel</button>
      </div>
    );
  }

  return (
    <button onClick={() => requestDelete(avatarKey)}>Delete Avatar</button>
  );
}
```

---

## One-step deletion

If your UI handles confirmation with its own modal or skips confirmation:

```tsx
const { remove, removeMany } = useDelete({ route: "avatar" });

// Single object removal
await remove(avatarKey);

// Batch object removal
await removeMany([avatarKey1, avatarKey2]);
```

---

## Options reference

| Option      | Default | Description                                              |
| ----------- | ------- | -------------------------------------------------------- |
| `route`     | —       | Required. Named server route (`dimahS3({ routes })`)     |
| `onSuccess` | —       | Callback on successful deletion: `(key: string) => void` |
| `onError`   | —       | Callback on failure with typed `APIError`                |

<Accordion title="How do I ensure only the owner can delete an avatar?">

Authorization runs on the server in `delete.guard`:

```ts title="lib/s3.ts"
avatar: route({
  delete: {
    guard: async ({ key, request }) => {
      const session = await getSession(request);
      if (!session) throw errors.unauthorized();

      const isOwner = await checkOwnership(session.userId, key);
      if (!isOwner) throw errors.forbidden();
    },
  },
});
```

</Accordion>

<Accordion title="How do I reset delete state after an error?">

Call `reset()` from the hook:

```tsx
const { reset, error } = useDelete({ route: "avatar" });

if (error) {
  return (
    <div>
      <p>Error: {error.message}</p>
      <button onClick={reset}>Try Again</button>
    </div>
  );
}
```
