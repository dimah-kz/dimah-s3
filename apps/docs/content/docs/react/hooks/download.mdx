---
title: Download
description: Presign a GET URL — native download, or fetch with progress.
---

Ask the API for a short-lived GET URL, then let the browser take the file.
Your server never streams the body.

Pass the **stored** key from upload (`result.key`) — a bare filename is
outside the route `keyPrefix` and returns `INVALID_KEY`. The route name
must have `download` enabled. Keys from an upload live on that upload
route — enable `download` there rather than adding a second route for the
same prefix ([combining features](/docs/server/routes#combining-features)).

| Hook                             | UI                                                                                                                |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| `useDownload()`                  | [Download Button](/docs/react/ui/components/download-button) — native download, no progress                       |
| `useDownload({ mode: "fetch" })` | [Progress Download Button](/docs/react/ui/components/progress-download-button) — `fetch` with progress and cancel |

Hook `error` is a `DimahS3Error` (or `null`). Format it with
`useFormatDimahError(error)` or read `error.message`.

## Navigate (default)

Presign, then navigate. There is no byte-level progress — only a
presigning phase.

```tsx
"use client";

import { useDownload } from "@dimah-s3/react";

export function DownloadFile() {
  const { download, phase } = useDownload({ route: "uploads" });
  // Persist `result.key` from upload — not the original filename.
  const storedKey = "uploads/11111111-1111-1111-1111-111111111111/photo.jpg";

  return (
    <button type="button" onClick={() => void download(storedKey)}>
      {phase === "presigning" ? "Preparing…" : "Download"}
    </button>
  );
}
```

Need the URL only — preview, embed, or your own link:

```tsx
const { presign } = useDownload({ route: "uploads" });
const result = await presign(
  "uploads/11111111-1111-1111-1111-111111111111/photo.jpg",
);
```

## Fetch with progress

Pass `mode: "fetch"` to stream bytes in the browser so you can show progress
and cancel.

```tsx
"use client";

import { useDownload } from "@dimah-s3/react";

export function DownloadFile() {
  const { download, cancel, progress, phase } = useDownload({
    route: "uploads",
    mode: "fetch",
  });
  const storedKey = "uploads/11111111-1111-1111-1111-111111111111/photo.jpg";

  return (
    <div>
      <button type="button" onClick={() => void download(storedKey)}>
        {phase === "downloading" ? `${progress.percent}%` : "Download"}
      </button>
      <button type="button" onClick={cancel}>
        Cancel
      </button>
    </div>
  );
}
```
