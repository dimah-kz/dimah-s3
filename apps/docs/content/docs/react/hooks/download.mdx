title: Download
description: Download hooks for native and fetch-based flows.
---

Two hooks cover common download flows:

- **`useDownload`** — presigns a URL and triggers a native browser download (no progress).
- **`useFetchDownload`** — downloads via `fetch` with progress and cancellation.

---

## Browser download

```tsx
"use client";

import { useDownload } from "@dimah-s3/react";

const { phase, download, presign } = useDownload();

// Trigger a native browser download
await download("reports/2024.pdf", "Annual Report.pdf");

// Or just get the presigned URL (for image previews, etc.)
const result = await presign("images/photo.jpg");
```

<Callout type="tip">
  `presign()` returns a URL without triggering a download — useful for **image
  previews**, video embeds, or building custom download links.
</Callout>

## Fetch download with progress

Downloads through `fetch` so you can show a progress bar and allow cancellation.

```tsx
"use client";

import { useFetchDownload } from "@dimah-s3/react";

const { phase, progress, download, cancel } = useFetchDownload();

// In JSX:
// <button onClick={() => isActive ? cancel() : download("file.zip")}>
//   {phase === "downloading" ? `${progress.percent}% — Cancel` : "Download"}
// </button>
```

## When to use which

| Scenario                    | Hook                        |
| --------------------------- | --------------------------- |
| Simple download link        | `useDownload`               |
| Image preview / custom link | `useDownload` → `presign()` |
| Progress bar needed         | `useFetchDownload`          |
| Cancellable download        | `useFetchDownload`          |
