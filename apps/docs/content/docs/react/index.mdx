[`@dimah-s3/react`](https://www.npmjs.com/package/@dimah-s3/react) is the
headless React client for dimah-s3. Its hooks take files in, check them
against the route's policy, and track progress, retries, cancel, and multipart
transfers. You render the UI.

Bytes move directly between the browser and the bucket. Credentials stay on
the server: the client sends a route name, and the server picks the object
key.

## How a hook works

```tsx title="components/avatar-uploader.tsx"
"use client";

import { useUpload } from "@dimah-s3/react";

export function AvatarUploader() {
  const upload = useUpload({
    route: "avatar",
    onSuccess: (result) => console.log("Stored at", result.key),
  });

  return (
    <div {...upload.getRootProps()}>
      <input {...upload.getInputProps()} />
      {upload.isPending ? `${upload.progress.percent}%` : "Drop an image"}
    </div>
  );
}
```

Every hook works the same way:

- **Server policy** — accepted types, size limits, multipart, and checksums come from the server's route catalog. Hook options can only narrow them.
- **State per file or key** — a list can show many transfers at once, and each one can be cancelled on its own.
- **Outcomes, not throws** — actions resolve with an outcome or a result. Errors are `APIError`s with a stable `code`. See [Outcomes and errors](/docs/react/guides/outcomes).
- **Any backend** — use [`@dimah-s3/server`](/docs/server), or implement the `S3Api` contract yourself. See [Bring Your Own Backend](/docs/react/custom-backend).

## Entries

| Entry                    | Exports                                                                                                   | Use it in                                      |
| ------------------------ | --------------------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| `@dimah-s3/react`        | Hooks, `S3Provider`, `useS3Api`, `createS3Client`, formatter hooks, and types                             | Client components. The build is `"use client"` |
| `@dimah-s3/react/engine` | Plain functions with no React import: `uploadFile`, `defineApi`, `memoryObjectSource`, stores, formatters | Shared modules, server modules, and workers    |

`APIError`, `S3_ERROR_CODES`, `validateFile`, and the other protocol helpers
come from [`@dimah-s3/core`](/docs/core), a peer dependency. The React package
does not re-export them. See [Requirements](/docs/react/setup#requirements)
for the React, Node.js, and browser versions.
