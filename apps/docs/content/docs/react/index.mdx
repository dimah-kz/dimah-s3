[`@dimah-s3/react`](https://www.npmjs.com/package/@dimah-s3/react) is a
standalone, headless S3 client for React. It handles file intake, progress,
retry, cancel, and multipart. You build the UI.

Like [Uppy AWS S3](https://uppy.io/docs/aws-s3/), it works as a standalone
client. It is also the React client used by dimah-s3.

Upload and download go straight between the browser and the bucket.
Credentials stay on the server.

<Accordion title="Upload, download, and delete">

Upload and download are presigned — the hooks talk to the bucket with a
short-lived URL. Multipart is part of upload.

<Callout title="Delete is not presigned">
  `useDelete` calls your API. The server removes the object. The browser never
  talks to the bucket for this step.
</Callout>

</Accordion>
</Accordions>

## What you get

- Headless — behavior and state without markup
- Standalone — works with any backend through `S3Api`
- Full flows — upload, multipart, download, and delete
- Optional UI — ready-made [shadcn controls](/docs/react/ui)
