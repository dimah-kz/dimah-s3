[`@dimah-s3/react`](https://www.npmjs.com/package/@dimah-s3/react) is the
browser client for dimah-s3. Hooks own state, progress, retry, cancel, and
multipart. You own the markup — or pair them with
[`@dimah-s3/ui`](/docs/react/ui).

The browser never holds long-lived credentials. Hooks ask your API for a
presigned URL, then talk to the bucket directly.

[`@dimah-s3/server`](/docs/server) is the usual backend. Your own presign API
works too — see [Custom backend](/docs/react/custom-backend).

List, copy, tagging, and other S3 APIs stay in your code with the
[AWS SDK](https://www.npmjs.com/package/@aws-sdk/client-s3).

## What you get

- **Headless** — state, progress, retry, and cancel; your UI
- **Full flows** — upload (including multipart), download, and two-step delete
- **Any backend** — `createS3Client` against dimah-s3, or `defineApi` against yours
- **Ready-made UI** — the same hooks, wrapped in
  [shadcn controls](/docs/react/ui)
