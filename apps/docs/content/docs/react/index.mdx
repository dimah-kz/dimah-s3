[`@dimah-s3/react`](https://www.npmjs.com/package/@dimah-s3/react) is the
headless React client for dimah-s3. It manages file intake, validation,
progress, retries, cancellation, and multipart transfers while leaving the UI
to you.

Uploads and, by default, downloads run directly between the browser and the
bucket; credentials remain on the server. Downloads can also use the server's
same-origin proxy mode.

## Key features

- **Headless architecture** — Transfer state and accessible DOM props without imposed markup or styles.
- **Presigned transfers** — Uploads and default-mode downloads bypass your application server.
- **Multipart support** — Automatic chunking for large files with resumable state via `UploadStore`.
- **Automatic constraint sync** — Loads file-size and MIME-type constraints from server route definitions.
- **Ready-made UI** — Optional accessible [shadcn components](/docs/react/ui) for common file controls.
- **Backend agnostic** — Use `@dimah-s3/server` or a complete custom `S3Api` implementation.
