Generate the tables with the package's CLI. Generating does not connect to
the database, so the script needs only the dialect:

```ts title="scripts/dimah-s3.ts"
import { DimahS3Db } from "@dimah-s3/db";
import { drizzleAdapter } from "@dimah-s3/db/adapters/drizzle";
import { runCli } from "@dimah-s3/db/cli";

await runCli(
  DimahS3Db.client(
    drizzleAdapter({ db: undefined, provider: "sqlite" }), // or "postgresql" | "mysql"
  ),
);
```

```bash
npx tsx scripts/dimah-s3.ts generate latest -o db/dimah-s3.ts
npx drizzle-kit push
```

- The file exports `storageObject`, `storageFolder`,
  `private_dimah_s3_settings`, and `relations`. Keep those exports and the
  table and column names: the adapter finds the tables by them.
- The tables declare their indexes and, on MySQL, the `utf8mb4_bin`
  collation, so `drizzle-kit` creates them too.
- Run `generate` again after you upgrade `@dimah-s3/db`. It overwrites the
  file. A column you add to it must be nullable or have a default: the
  plugin does not write it.
