The tables ship prebuilt in `@dimah-s3/db/drizzle/sqlite`, `/pg`, and
`/mysql`. Re-export them from your schema file so `drizzle-kit` creates them
next to your own tables:

```ts title="db/schema.ts"
import { dimahS3Tables } from "@dimah-s3/db/drizzle/sqlite"; // or /pg, /mysql

export const { storageObject, storageFolder, private_dimah_s3_settings } =
  dimahS3Tables;

// Your own tables go here.
```

Keep the three names as they are. The adapter finds the tables by these
keys, and it reads the schema version from `private_dimah_s3_settings`.

```bash
npx drizzle-kit push
```

The tables carry the secondary indexes, so `drizzle-kit` creates those too.
On MySQL, the tables set the same collations as `sql/mysql.sql`:
`utf8mb4_bin`, so keys and folders compare byte for byte, and
`utf8mb4_unicode_ci` on `filename`, so search ignores case.
