The models ship in `prisma/dimah-s3.prisma`, with no generator or
datasource. With a multi-file schema, copy the file into your schema folder.
Otherwise, paste its models into `schema.prisma`.

```bash
cp node_modules/@dimah-s3/db/prisma/dimah-s3.prisma prisma/schema/
npx prisma migrate dev --name dimah-s3
```

Keep the model names `StorageObject`, `StorageFolder`, and
`private_dimah_s3_settings`. The adapter calls them by name. The models
declare the secondary indexes, so the migration creates them too.

The models work as they are on PostgreSQL and SQLite. On MySQL, follow the
header of the file: add `@db.VarChar(1024)` to `key`, `folder`, `path`, and
`parent`, `@db.DateTime(3)` to the timestamps, and index prefixes such as
`@@unique([bucket, key(length: 512)])`.
