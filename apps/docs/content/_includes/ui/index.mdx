Mount the toaster once in your root layout:

```tsx title="app/layout.tsx"
import { Toaster } from "@dimah-s3/ui";

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body>
        {children}
        <Toaster />
      </body>
    </html>
  );
}
```

Already using shadcn [toast](https://ui.shadcn.com/docs/components/base/toast) for your own messages? Mount both — rename one import (`Toaster as DimahToaster`). They are independent; your code keeps `import { toast } from "@/components/ui/toast"` and `toast.add({ … })`.

<section id="shadcn-registry-setup">

```json title="components.json"
{
  "registries": {
    "@dimah-s3": "https://dimah-s3.vercel.app/r/{name}.json"
  }
}
```

Dimah-owned chrome uses `--color-dimah-s3-*` tokens (default: your shadcn theme).
If you are not importing `@dimah-s3/ui/styles.css`, add the
[color bridge](/docs/react/ui/theming#shadcn-registry-only) to `globals.css`.

Components depend on shadcn [toast](https://ui.shadcn.com/docs/components/base/toast). After `npx shadcn@latest add …`, mount once:

```tsx title="app/layout.tsx"
import { Toaster } from "@/components/ui/toast";

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body>
        {children}
        <Toaster />
      </body>
    </html>
  );
}
```

Trigger toasts with `toast.add` / `toast.update` / `toast.close` / `toast.promise` from the same module — not the old Sonner helpers (`toast.success`, `toast.error`, …).
